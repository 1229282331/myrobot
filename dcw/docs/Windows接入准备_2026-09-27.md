## 插线后的测试顺序

1. 用支持数据传输的 USB 线将 DCW 接到本机直连接口；相机由 USB 供电及通信。
2. 读取 USB 枚举和驱动状态；需要时安装包内官方驱动。
3. 用匹配的 v1 Viewer 读取型号、序列号、固件和支持的流模式。
4. 分别测试彩色与深度，再测试双流。初始候选 RGB 1280×720@30 MJPEG、深度 640×480@30，最终以设备枚举及实际运行结果为准。

官方支持和本机平台匹配已确认；实际识别、成像、双流帧率和稳定性尚未验收。
