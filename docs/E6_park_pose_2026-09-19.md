# E6 候选 park_pose 实机记录

日期：2026-09-19（Asia/Shanghai）

## 结论

本次为放在桌边的裸臂选定并实测了一个候选停放姿态：

```text
[J1, J2, J3, J4, J5, J6] = [0, -60, 120, 0, 45, 0] 度
```

相对全零姿态，它让 J2/J3 折叠，末端更紧凑；这个姿态来自官方 E6 模型的静态运动学分析和低速实机验证。它是本台设备的当前候选 park_pose，不代表控制器内置的“安全姿态”，也不能替代现场碰撞检查。

## 实机动作

- 机器人：Dobot Magician E6，IP `192.168.1.4`
- 控制模式：TCP/IP
- 起始角度：`[0, 0, 0, 0, 0, 0]` 度
- 指令：`MovJ(joint={0.000000,-60.000000,120.000000,0.000000,45.000000,0.000000},a=3,v=3,cp=0)`
- 控制器队列 ID：`3`
- 速度/加速度比例：`3% / 3%`
- 到位条件：最大关节误差不超过 `0.1°`，连续 3 次反馈满足
- 结果：约 102 秒到位；随后保持 `RobotMode=5`（使能、空闲），没有自动下使能
- 报警：`GetErrorID()` 返回 `[]`

到位后的只读反馈如下：

```text
GetAngle() = [0.0000, -60.0000, 120.0000, 0.0000, 45.0000, 0.0000] 度
GetPose()  = [-37.7819, -130.4439, 432.7599, -39.2315, 37.7612, -116.5651]
```

完整复核文件：`local-network/e6-readonly-after-park-20260919-010844.json`。

## 使用与边界

脚本 [tools/e6_park.py](../tools/e6_park.py) 默认只读预览；只有带 `--execute` 并输入 `GO PARK` 才会发出一次运动命令。脚本会检查模式、报警、反馈新鲜度和起点到目标的关节范围，异常时尝试发送 `Stop()`，不会自动重试或自动下使能。

日常需要直接执行时运行 [tools/e6_park_direct.py](../tools/e6_park_direct.py)：

```powershell
python tools/e6_park_direct.py
```

这个入口固定使用已验证的 IP、目标角度和 3% 速度/加速度，自动完成一次执行；如果已经在目标容差内，则不会再发送运动命令。运动完成后仍保持使能空闲。

下次关机前可以先观察该姿态是否确实收在桌内侧，再按实际关机流程下使能。桌面尺寸、桌边方向、底座固定方式、线缆和未来末端工具改变后，应重新做低速验证；仅凭 URDF 或 TCP 坐标不能证明现场无碰撞。
