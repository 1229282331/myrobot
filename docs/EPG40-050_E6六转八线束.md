# EPG40-050 八芯版接 E6：无源六转八线束

核查日期：2026-09-19。用户优先要求端部插接使用、接受机械法兰转接，并提出购买六芯转八芯航插。本次仅查资料与采购渠道，未操作机器人、发送 IO、联系商家或采购。

## 结论

如果实物 EPG40-050 的控制输入兼容 E6 的 24V PNP DO，且状态输出兼容 E6 的 DI，则可使用按功能重排线序的无源转接线；不需要把 RS485 转换为 PNP。夹爪八芯中的两芯 RS485 在纯 IO 使用时不接，余下六芯为供电和两进两出。

目前没有核实到标明 E6→EPG40-050、线序正确、可直接下单的成品 SKU。已核实连接器厂家提供线束定制服务；能否接一根、是否能匹配两端连接器、价格和交期尚未取得报价。因此结论是“可按定制线束路径采购”，不是“已找到即插即用现货”。

## 供加工方复核的针号表

依据：E6 官方 V1.4 第 6.2 节（印刷页 22）及钧舵 EPG A.2 表 3.2（印刷页 8）。这是条件式设计表，不是已经与所购实物匹配的施工图。针号按各自手册；不代表面向插头、插孔或焊接面的空间位置。

| E6 六针 | EPG 八针 | 功能 |
|---|---|---|
| 1：24V | 5：DC24V | 供电；须先确认末端电源能力 |
| 6：GND | 8：DC0V | 电源参考地 |
| 2：DO1 | 7：IN1 | 控制输入 1 |
| 3：DO2 | 6：IN2 | 控制输入 2 |
| 4：DI1 | 4：OUT1 | 状态输出 1；电气匹配后接入 |
| 5：DI2 | 3：OUT2 | 状态输出 2；电气匹配后接入 |
| 不接 | 1：485A、2：485B | 分别绝缘悬空 |

普通 1→1、2→2 的直通接法不适用，例如 E6 的 1 脚是 24V，而 EPG 的 1 脚是 485A。屏蔽/PE按实际线束及厂家规定处理，不把屏蔽线默认当电源地。

## 尚需匹配的条件

- **连接器**：尚无 E6 端连接器的确切系列、螺纹、键位和对接件料号。不能直接按“六芯”买 GX12、GX16 或 M8。EPG-HP 资料中的 M12-8FA-S8-5000-P 不能直接当作任意 EPG40-050 的线缆订货号。优先用双方原装配套线保留接头，由线束店制作短线，或提供原厂配对件。
- **IO 电平**：商家说“485+IO”不能代替输入/输出电路确认。钧舵 A.2 的带公共端示意图不能直接套用到八芯版本。CobotG 在线手册还描述开漏输出及上拉要求，不能据此把所有八芯状态输出视为可直接送出 PNP 高电平。
- **供电**：现有 EPG40-050 参数为 24V、额定 0.4A、最大 0.85A。E6 末端 24V 针脚独立持续/峰值上限尚未明确，须由越疆确认，不用全机 IO 总 2A 或 DO 单路 0.5A 推导。无源线不会解决供电不足。
- **配置**：要求交付前设置并保存 IO 模式、开合预设、速度和力，并演示断电重启后在不连接 485 的情况下完成 IO 初始化与开合。IO 模式控制开合/预设，不提供 RS485 的连续数值反馈。
- **成品验收**：断电状态下逐针对照导通、检查短路及未用针隔离；核对公母针、键位和观察面。随后在固定好的独立夹爪台架验证，不以接上 E6 试错作为线序检查。
