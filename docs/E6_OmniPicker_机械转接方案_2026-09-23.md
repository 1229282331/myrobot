# E6 与 OmniPicker：单片铝盘转接方案

日期：2026-09-23。用户已确认夹爪到货。本轮核对官方后盖工程图、装配图、E6手册，并静态读取后盖STEP；没有拆机、通电、连接机器人或进行运动测试。

## 推荐结论

推荐保留OmniPicker原后盖，定制一块6061-T6铝合金圆盘：E6法兰 → 转接盘 → 原后盖 → 夹爪本体。两侧孔圈不同，需要转接；未确认有可直接购买、适配本台实物的成品。此方案是可供机械加工方深化的结构方案，实物尺寸、沉头螺钉标准及装配净空核对后才能出生产图。

关键是装配顺序：先把盘固定到E6，再从后盖内侧用M3螺钉把后盖固定到盘，最后将夹爪本体套回后盖并锁紧侧面的4颗M2.5螺钉。官方图证明这些M2.5固定螺钉为侧向安装，不需要从被E6遮挡的背面操作。此顺序可避免普通平盘“整只夹爪先装好后，E6螺钉被遮住”的问题。

|---|---|---|
| E6工具孔 | 4×M6，PCD 50±0.1 mm，深6 mm | 官方手册V1.4 §5.4、§7.3.2推荐的工具安装接口 |
| E6其他孔 | 8×M3，PCD 56±0.1 mm，深6 mm | 本方案不使用 |
| E6定位 | Φ6 H7孔深4 mm；另标Φ31.5 H7、Φ63 h8 | 定位销、止口的高度与配合按实际端面测量确定；不能只抄直径 |
| 后盖外径 | Φ57 mm（官方图带单向公差） | 当前官方后盖参考值，不代表二手实物已量过 |
| 后盖轴向安装孔 | 中心1孔＋外围4孔，均为Φ3.2通孔；外围PCD 25±0.1 mm | 是通孔，不是M3内螺纹；官方后盖STEP的Φ3.2圆柱轴也分布在中心与±12.5 mm坐标附近 |
| 后盖内侧沉孔 | 5×Φ6，深1.5 mm | 限制螺钉头直径/高度，应使用与原厂示例相符的超短头M3 |
| 后盖连接本体 | 侧向4×M2.5；装配示例用M2.5×8沉头螺钉 | 不与后盖轴向安装孔混淆；装回时核对螺钉原规格和状态 |

官方X1装配示例采用3颗超短头M3×6把后盖固定到X1支架。本方案初设使用外围4孔提高布置对称性；四处内侧螺钉与实物PCB/零件的净空须确认。中心孔保留，不把原厂“三颗”描述成原厂要求“四颗”。

## 圆盘初设参数

以下属于工程建议，不是官方E6专用转接件图纸。

| 特征 | 初设 |
|---|---|
| 材料、外形 | 6061-T6铝，外径65 mm，两安装基准面间厚7 mm；边缘倒钝；可阳极氧化 |
| E6侧固定 | 4×Φ6.6通孔，PCD 50，均布；从夹爪侧加工90°沉头座，尺寸匹配所选M6沉头螺钉，头部不高出贴合面 |
| 初选E6螺钉 | 4颗M6×12沉头内六角；沉头螺钉长度含头，7 mm夹持厚度下名义穿出5 mm，距标称6 mm孔底留约1 mm。仍需核对实际头形、沉入量、有效牙和孔底，不能换成普通圆柱头后沿用这个算式 |
| 夹爪侧固定 | 4×M3×0.5螺纹孔，PCD 25，均布；初设有效牙4.5–5 mm，底孔深度与7 mm厚度配套。相对E6孔圈及接口的转角需在CAD中定稿 |
| 初选后盖螺钉 | 4颗超短头M3×6作为候选；头部须适配后盖Φ6×1.5沉孔并避开PCB。伸入量=实际螺钉有效杆长−后盖实际剩余夹持厚度，按实物复核；不直接用普通M3圆柱头替代 |
| 定位 | 可利用E6预留Φ6 H7定位孔，插入端建议≤3 mm（原孔深4 mm）；销总长、配合和盘内固定方式待端面复核。Φ31.5中心止口如要使用，须先量深度和凸凹关系 |
| 贴合及螺钉避让 | 保持两安装面贴合，M6头必须齐平或微低；后盖若有凸台、原有螺母或隔柱，需核对是否妨碍贴合。不要靠拧紧螺钉把干涉件压平 |
| 线缆 | 按实际Type-C插头、六芯锁扣和E6航插朝向选装配转角；转接盘有遮挡时局部开避让口。边缘做应力释放固定点，线缆不夹在两贴合面之间 |

本方案第一版可先不挖大面积减重槽，保持工艺简单。需要减重时，只在非贴合/非传力关键区开背面口袋，保留M6孔周、M3螺纹区和径向连接筋，再复核刚度和疲劳；不在未分析时承诺某个减重后的承载能力。

## 装配顺序

1. 断电、支撑好本体；只拆后盖侧面4颗M2.5固定螺钉，分离后盖，不拆PCB。
2. 转接盘先用4颗M6沉头螺钉固定到E6。核对孔底余量、定位及头部不突出贴合面。
3. 将原后盖置于盘上，用M3超短头螺钉从后盖内侧穿过Φ3.2通孔，拧入盘的M3孔；确认螺钉不压到PCB或零件。此时夹爪本体尚未装回，所以有工具操作空间。
4. 将夹爪本体装回后盖，按原规格恢复4颗侧向M2.5螺钉。原厂手册提示拆卸过的螺钉更换新件；复用孔位与结构，不把紧固件状态视为已合格。
5. 检查USB及六芯线插拔、锁扣和弯曲空间，称量整套末端，更新工具质量、重心和TCP。首次运动前检查底座、工具、线束及已知关节保持问题。

不提供未经原厂或紧固件/螺纹材料核实的锁紧扭矩。只按手感大力拧紧小螺钉可能损坏后盖或铝螺纹。

## 重量与负载

- Φ65×7 mm实心铝圆盘，按密度2.70 g/cm³计算约62.7 g；扣除安装孔后略轻，约55–60 g可作为未精建模前的估计范围。紧固件、定位件另计，整套新增转接件先按约70 g预算。
- 夹爪若实称430 g，合计约500 g，距E6标称750 g尚余约250 g供相机、支架、线缆与物体共同使用；这只是质量差额，不是允许抓取重量保证。
- E6手册§5.5要求按合成质心偏心距离降额，60 mm以内上限750 g，超过60 mm下调。增加7 mm安装厚度会把夹爪及物体质心向外推，需按合成质心与负载曲线复核。
- 既有J4/J5下使能回落问题仍未解决，不能把加装夹爪当作保持问题已解决；装配时可靠支撑，运动验证另行开展。本轮没有任何硬件操作。

## 下单前只需补齐的实物信息

1. 后盖正面与侧面照片、实际外径、外围相对孔中心距（官方候选值25 mm）及孔型；确认用户早先照片中两处金色螺母/隔柱的用途、是否妨碍贴合。不能直接假设可以拆掉。
2. 后盖内侧沉孔与螺钉头部净空；E6安装孔可用深度、定位结构及实际接触面，中央原有结构螺钉不得被转接盘顶压。孔深测量以断电机械测量为前提。
3. 夹爪实称重量，以及插入实际USB/六芯插头后的方向和外形。

这些信息用于把当前“方案”转成投产STEP和尺寸图；不要求为了讨论方案先上电。
