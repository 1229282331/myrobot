# E6遥操作自动恢复策略

用户于2026-10-06要求以后自动重试可处理的异常，避免每次人工确认打断开发和遥操作。本次实现的是有条件、有限次数的自动恢复准备；未确认的旧动作仍不补发，不保证发生异常时毫无停顿。

启动时选择 `--recovery-policy bounded|manual`，PC CLI默认`bounded`。模拟和hardware-observe行为不变；只在hardware-control使用该策略。底层直接构造控制器仍默认manual，兼容既有替身测试。策略固定在会话启动时，操作者验收档案必须绑定相同策略及新源码SHA。

## 恢复流程

1. 已分类的计算、事务、循环预算或反馈新鲜度超时先撤销旧租约并请求停止；超时但可能已发送的运动保留不确定标记，按原连接处理迟到回包。
2. 实机须Stop确认、实际静止、无排队目标、正常使能、无碰撞/报警/参数变化，反馈仍满足100ms和RGB500ms门槛。
3. 同一控制者、同一输入设备须持续提供新序号的回中输入，松开允许动作键、保持焦点和连接。至少5秒连续健康且静止，原稳定保持及工作区检查都通过，才自动调用准备步骤。一直按着摇杆不会重新启动。
4. 准备只进行必要的只读运动学验证及连接准备，不发ServoJ或CAN；目标从当前实际姿态重新建立，原工作区基准不移动。初始化、使能、清错、Continue、负载/TCP/碰撞参数都不自动执行。
5. 自动准备后不发空闲CAN持有命令；重新按住允许动作键才处理新输入。旧目标不重放、丢失周期不补偿。

每60秒最多3次自动准备尝试，失败采用有界退避；单次恢复等待最多30秒。达到次数或等待上限后保留停止状态，需要检查并重新准备。原50ms控制事务、150ms目标完成、250ms输入租约以及速度/加速度/工作区边界不变。

## 保留停止的异常

碰撞、堵转/state2、夹爪故障或通信结果不确定、关节限位/无解/IK残差、根因未明的关节差值、停止未确认、反馈解析/控制器重启、写盘/证据队列错误都不直接自动续动。显式Back/Esc/Stop、失焦、输入身份改变或控制连接断开也不能被自动恢复撤销。源流或进程真正退出仍需重建会话，新会话不能继承旧动作。

正在发送的事务被看门狗取消时，守护进程保留具体超时原因；CAN尚未发送的取消不误记为夹爪物理故障。真实CAN缺回包仍保持故障锁止。状态及原始事件分别记录故障、自动准备尝试、成功及新输入恢复；录制遇到故障仍保留中止片段，不自动拼接或把后续状态填成旧动作。

## 验证与当前边界

离线回归Windows400通过/1项Linux专用跳过，WSL401通过；自动恢复专项24项，覆盖旧输入不执行、持杆不重启、新方向输入、源/焦点变化、停止未确认、连续反馈健康、物理异常、3次限额、30秒等待和只读准备失败。前端7项测试及构建通过。

v39真实E6/相机影子矩阵完成600.900秒、12017帧、5752候选周期，160类生产映射全覆盖，必需观测失效0，运动/Stop/CAN发送均0。逐帧原SDK读回通过，IK/FK墙钟P99 19.924 ms、最大23.950 ms。29.501秒影子故障注入的589帧也逐帧通过：前三次输入租约超时经5秒新回中输入自动准备，第四次触发次数上限，设备发送仍全部为0。

随后在已使能静止的实机执行14.647秒零增量恢复测试，292帧必需观测全部有效。通过真实手柄映射、PC及X5链路发送4条确认的零增量ServoJ，再注入一次输入租约超时；Stop确认和静止回读通过，至少5秒健康回中后自动准备。独立审计核对原SDK、输入、实际命令与恢复事件：恢复准备期间27个回中周期没有旧目标、ServoJ或CAN发送。两次Stop发送最大0.353 ms、控制器确认最大509.461 ms；后者是协议确认时间，不能等同物理制动时间。实际关节前后最大变化约0.001374°，仅为零增量保持回读。本轮未再次使能、初始化夹爪或发送CAN，也没有非零恢复后运动测试。

实机零增量验证覆盖一次输入租约恢复，不替代运动中其他故障、连续旋转、连续夹爪及最终实体输入验收。完整operator档案仍未完成，实体控制保持禁用；当前工作台恢复shadow/harness/initial/5Hz，E6保持使能，CAN DOWN。前一v38实机结果保留为历史证据，不迁移为v39交付通过；关键SHA修改后仍须重新验证。

固定35%夹爪留证诊断6秒120回完成，state0/fault0，位置raw88→89（34.51%→34.90%）。它主要覆盖接近目标时的一计数收敛及保持：此前固定35%命令在CAN关闭后仍可作为夹爪内部目标，不能把本段称为从27%完整张开到35%或连续遥操作通过。原连续开度state2和首次固定目标关节保护中止仍保留；异常发生率和根因未确认。退出时CAN DOWN不等于夹爪24V已断电。
