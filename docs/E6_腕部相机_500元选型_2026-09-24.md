## DW2、DCW2 与 DCW 的补充核查

用户随后询问 DaBai DW2。官方 [《DaBai DCW2-DW2产品规格书（三防版本）V1.0》](https://xm917ch2uk.feishu.cn/file/ZXA0bdea9oWv0zxmtfjcKF3nnNq) PDF第11页明确写“备注：DaBai DW2 无 RGB”。因此 DW2 不能独立作为本项目 RGB 策略腕部相机，不能因卖家标题并列 DCW2/DW2 就套用带彩色版本参数。

| 参数 | DaBai DCW（V2.5规格书） | DaBai DW2（三防版V1.0规格书） |
|---|---|---|
| RGB | 有，最高1080p30 MJPEG | 无；仅深度/红外不能当彩色输入 |
| 深度范围 | 0.2–2.5m | 常规0.15–3m，高能级0.15–5m；只适用于该规格版本 |
| 深度FOV（不开D2C） | H79° V62° | H91° V62°（640×400模式） |
| 深度帧率 | 多种模式最高30fps | 640×400等模式最高15fps |
| 尺寸 | 89.82×25.1×25.1mm | 相同 |
| 通信/供电 | USB2.0、Type-C | USB2.0、Type-C |
| 标称重量 | 88.3±3g | 联合规格表合写88.1g，未分别列DW2与DCW2，不能据此精确比较两者重量 |

命名关系仅对这四款适用：DW/DW2无RGB，DCW/DCW2带RGB。DW2是更偏深度避障的二代版本，不是更适合RGB腕部学习的DCW替代品。

版本差异必须保留：[DCW2官方产品网页](https://www.orbbec.com.cn/index/Product/info.html?cate=38&id=55)列最近0.2m、RGB及深度15fps；上述三防版V1.0则列最近0.15m，RGB的MJPG模式可30fps、深度仍最高15fps。不能将网页与PDF拼成统一全型号规格；购买DCW2时需核对具体料号/固件与输出模式。该三防版表列DCW2 G10254-001、DW2 G11254-001。

软件核查：[OrbbecSDK_v2 当前README](https://github.com/orbbec/OrbbecSDK_v2)将DW/DCW/DCW2/DW2列在 OpenNI→UVC 的 **Future Upgrade Schedule**，不在已升级设备列表。搜索引擎摘要把DW2说成已支持v2不可靠；现有二手设备应核对协议/固件，优先对应OpenNI或SDK v1，不能默认已有v2支持。未刷机或运行驱动。

## 结论

严格控制在 500 元以内，优先核验 **DaBai DCW（360 元）**，其次 **Gemini 一代（399 元）**；预算优先可考虑 **普通 DaBai RGB-D 模组（229 元）**。这三款是候选，不等于已经验证实物的重量、成像和开发板兼容性。

**不能把 DaBai Pro、DaBai Max 当作普通 DaBai 的全面升级版。** 本次找到的大白 Pro 官方结构图仅列两个红外相机、红外投影仪及安全传感器，没有 RGB 相机；不适合单独充当 RGB 视觉策略的腕部相机。早期搜索中发现的 165/239 元 Pro 条目已从推荐中排除。

若要求镜头到物体仅 10–15 cm 时仍有可靠深度，上述便宜旧款都不是有规格保证的选择。D405 更适合近距离腕部，但本次货源超出预算。深度最近距离与 RGB 最近清晰距离是两回事，不能将前者当作彩色镜头对焦规格。

## 学术与工业生态：有使用证据，不编市场占比

- **ALOHA 2** 原始项目明确写使用 RealSense **D405** 与 3D 打印安装件，理由包括体积、视场、深度和全局快门。它是与腕部操作直接相关的参考，比导航机器人的装机数量更有意义。[项目](https://aloha-2.github.io/)
- **LeRobot** 当前相机文档列出原生 `RealSenseCamera`（含深度），以及 `OpenCVCamera`、`ZMQCamera` 等。RealSense 的优势是现成接入路径；当前内置类表没有旧款奥比专用类，不代表第三方完全无适配。奥比需先验证 RGB 的 UVC/OpenCV 路径，或用对应 SDK 编写适配器。[文档](https://huggingface.co/docs/lerobot/cameras)
- **APT（2026）** 论文附录 E.1 明确写 Piper + 两台 ORBBEC DaBai，分别作为外部及腕部视角，采集 640×480 RGB-D，并进行 π0.5 对比。这证明奥比大白可用于具身研究；论文未精确给出硬件后缀，不能将其认定为本次任何一个闲鱼 SKU，也不能据此保证普通 DaBai 原生深度分辨率就是 640×480。[论文](https://arxiv.org/html/2606.12366v1#A5.SS1)
- **工业部署**：奥比官方案例文章将 DaBai 对应高仙清洁机器人、DaBai Pro 对应普渡配送机器人、DCW 对应工业 AMR。来源是厂商报道，用于证明存在商业部署，不能据此认定这些型号在工业界占比最高，或导航配置最适合机械臂近距离操作。[厂商文章](https://www.orbbec.com.cn/index/News/info.html?cate=31&id=223)

不需要为了 ACT、Diffusion Policy 或 openpi 的 RGB 策略特意购买 IMU 或深度功能。稳定清晰的 RGB、帧率、时间戳和一致的安装视角是首要项；使用点云/深度方法时再确保近距离深度有效。

## 旧奥比软件版本是采购条件

官方 [OrbbecSDK 仓库](https://github.com/orbbec/OrbbecSDK)说明：v2 不支持旧 OpenNI 协议设备。v1 列表包含 DaBai（最低固件 2436）、DaBai DCW（2460）、Gemini（3018）；不要买回后直接默认最新版 SDK v2 能识别。

v1 列出 Windows、Linux x64、Linux ARM64 支持。RDK X5 / Orange Pi 5 Pro 可以作为集成目标，但这不是两块板上已实测可用的结论，要核对 OS、SDK 二进制/源码与 USB 设备枚举。优先保存可工作的 SDK、固件和采集配置，不盲目刷固件。

官方 [资料下载目录](https://www.orbbec.com.cn/index/Download2025/info.html?cate=121&id=1)本次显示：Gemini 一代、大白 Pro 已停产；普通大白计划停产。对低成本原型有意义，长期复制多套设备则需考虑维护。

## E6 负载与接线

- E6 标称 750 g。若 OmniPicker 暂按 430 g 预算、R2 铝转接盘按 CAD 理论 54.36 g，则相机、相机支架、紧固件、随动线缆和物体共同只剩约 **266 g**。夹爪与转接盘并非本次实称。
- 工程目标：相机加安装件和腕部线缆尽量控制在 **100–120 g 内**，给物体留约 146–166 g 的算术余量；实际仍要满足重心、力矩和运动工况。三个便宜候选的净重均未得到可信实称，必须在最终购买前补齐，不使用包装重量代替。
- 相机固定于夹爪的固定壳体或腕部转接支架，尽量靠近法兰、朝夹指前方观察；不装到会开合的活动夹指，不挡 USB/电源插口。
- 相机以一根合适的 USB 数据线同时供电和传图，沿机械臂布线，到底座旁的 RDK X5 / Orange Pi；开发板再经局域网连接 PC。开发板放底座旁，不增加腕部重量。相机不接 E6 的 PNP 接口。
- 在接头附近做应力释放，各关节留合适活动弯，避免拉扯镜头或把线跨过工作空间。Wi-Fi 只用于上层传输，并不会消除相机到开发板的随动线缆；采集应在开发板侧记录时间戳、检查丢帧/延迟。
