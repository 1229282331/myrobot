## 候选变化与依据

使用 v325 的查询调度作为基线；v326 双样本并行候选没有通过，未沿用。每个连杆对含多个形状时，所需结果是所有形状对的最小距离。原实现虽然在形状根包围体层共享上界，进入每个 FCL 网格内部后却继续计算独立精确距离，重复探索不可能改变整体最小值的分支。

候选将同一个姿态、同一个连杆对的表面见证点距离上界传给各形状内部 FCL 遍历。上界来自当前形状的三角形或同连杆对其他形状的三角形，既不来自旧姿态，也不是碰撞许可。所有可能改善最小值的分支仍由原生 FCL 检查。只有本形状对新得到的有效三角形编号才能写入其热启动见证缓存；借用的跨形状上界没有本形状见证，不得缓存为其距离。

不改变模型、ACM、连续路径证明、夹指不确定范围、单调退离条件、37/42/50 ms 截止或 100/250 ms 新鲜度。源与补丁保存在 `output/compound-upper-v328/source`、`compound-upper.patch`；尚未覆盖正式 native 源或发布 pin。

## C 独立候选：近距路径的有界分离证书
