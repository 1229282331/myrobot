## 假设、修改和回归

v212 的六次 95–105 ms 发送间隔，均在固定检查时看到 `already_consumed` 或 `no_candidate`；下一候选随后到达，却未唤醒消费者。例如 ID5263 到达后又等约37 ms才被消费。完整原窗口在 `evidence/candidate-cadence-v213/original-gaps.json`，不能据此将全部跟随偏差都归为同一个根因。

C++适配现在对每个新鲜的新ID通知原事件；已消费、重复和旧ID不覆盖最新候选、不更新时间戳、不重复唤醒。首候选统计仍只记录epoch首条。发送前保留至少50 ms间隔，不因通知增加突发发送；健康、释放和回包处理在限频前执行。周期快照按独立50 ms deadline采样，错过的时段不补采，所有动作事件仍完整记录。ROS路径保持原首候选通知与记录方式。

102项专项、完整后端623通过/7平台跳过，14条上游Pydantic警告，无失败。源码SHA和XML保存在 `evidence/candidate-cadence-v213`。前端未改，复用v206构建与115项结果，不声称重新测试。
