## 假设与改动

v200 的最慢反馈窗口包含 X5 内部等待及文件页面缺页；同进程 ZIP/SHA 工作可能争用 Python 执行与内存资源。把现有 `Episodes._bundle` 的文件排序、压缩、manifest 与 SHA 算法移到标准库独立解释器，保留原录制、媒体暂存及校验回传链路。控制、设备协议、时效与运动参数不变。

`episode_bundle.py` 通过 `sys.executable -I -S` 启动，子进程不导入设备模块；父进程沿原动态退出期限轮询，只终止并回收自己创建的子进程，错误保留源文件与 `.part`。压缩算法仍是 Python `zipfile`，原 `.bin` 为 STORED，其他文件 level 1 DEFLATED。
