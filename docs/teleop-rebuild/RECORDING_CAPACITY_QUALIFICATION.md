## 实现

沿用固定phosphobot完整应用的Recorder、原Episodes工作线程与ArchiveStore，不引入第二个记录器。ArchiveStore公开已有预算，统计单位为归档Zstd压缩前的原始图像载荷（RGB为采集得到的JPEG，深度为uint16原字节），不是磁盘剩余空间，也不是所有RGB未压缩大小。

Episodes仅在独立工作线程读取相机状态，复制容量信息到已有状态消息；state()/输入/Stop/原始反馈路径不增加文件IO。开始前显示本段0用量；新片段重新计量；完成后保留封存时的最终用量。旧版无预算字段时显示未知而非无限容量。网页展示已用/上限、进度和80%预警，提醒结束保存后另起片段；预警不会改变控制状态或关闭结束按钮。到达原限制仍中止并保留，错误名从disk budget改为image payload budget，避免误认为磁盘已满。
