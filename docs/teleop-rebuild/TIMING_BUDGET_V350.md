## 评价方式

最终比较采用同一模型、相同输入和同一负载，关注：

- 每分钟暂停次数、换向与退离是否连续，准备状态是否异常取消。
- 输入到实际指令发送的延迟分布，发送节拍和实际关节跟随曲线。
- 松手、显式 Stop 和失联时的指令停止及实际静止时间。
- 模型检查是否完整、反馈与输入到写口时的实际年龄。

计算预算、进程通信余量、请求时限、Servo 积分周期和设备发送周期需要联合分析。如果改变周期，须同时核对速度、加速度与平滑器的时间基准，不能只改 Python 等待时间。反馈和输入新鲜度、停止处理分别评估，不自动随计算预算一起增大。
