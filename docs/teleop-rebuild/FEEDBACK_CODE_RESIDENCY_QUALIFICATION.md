# 反馈代码页驻留验证

2026-10-09。沿用正式 phosphobot / 官方 SDK / MoveIt C++ 链路。此项只处理 X5 进程内存驻留，不扩大实机运动空间，不改变速度、控制期限或控制器参数。完整平台目标仍未完成。

## 假设与真实定位（v208）

v207 的最慢接收窗口中，网口仍持续收到反馈，接收线程却在 futex 等待，且网关进程发生 major fault。v208 改用系统 perf 的 major-fault 事件和调用链；每秒一次 proc 采样，不再读取审计尾文件。四个 16 MB TCP 环限制捕获空间。

正式静止 shadow `20261009-144439-0392c25a` 中，48681 个 SDK 帧有效、无缺号，均 Mode5 / Enable1 / Error0 / Collision0；没有准备、运动、Stop 或 CAN。约 50.235 秒片段保存 993 周期、2002 原图、6134 SDK 反馈，原媒体回传校验完成，采图关联失效为零。

380.299 秒捕获的 TCP 环实际保留 296.639 秒，36175 帧唯一匹配。时钟括号宽度 2.091 ms，网口到接收上界 P95 5.114 ms、最大 27.411 ms。本次没有复现 ≥50 ms 接收慢点，不能把它当修复前故障必现。

perf 解析出 39 个 major-fault 事件，其中 15 个来自网关，24 个来自独立封存子进程。网关调用链涉及 NumPy、SciPy、Python 与 Pydantic 的运行库页面，证明这些页面会从存储重新载入；不等于证明缺页耗时、GIL 持有者或历史秒级停顿根因。perf 正常收到 SIGINT 后退出码为 −2，文件封存及 script 解析成功；55674 次 wakeup 和采样器 P95 9.324 / max 11.583 ms 开销均保留。

证据：[feedback-faults-v208](evidence/feedback-faults-v208/)、[live-jazzy-v208](evidence/live-jazzy-v208/)。正常退出与资源审计通过，CAN RX/TX 196367 未增加；临时捕获文件逐 SHA 核对归档后已释放。旧版本 probe 辅助文件不作为新执行证据。

## 可重复无设备对照（v209）

实际 SDK FeedbackReader / Audit / idle NativeExecutor 连接受限 socketpair，独立 producer 每 8 ms 发送固定 1440 字节反馈，仅替换同机发送时间戳。没有启动设备 executor，没有 E6、CAN、相机连接。

default / locked / locked / default 顺序，每组 15 秒，对本进程 NumPy 的 3936256 字节可执行映射发起六次页面回收挑战。没有修改库文件、全局缓存、调度或其他进程。locked 使用标准 Linux `mlockall(MCL_CURRENT)`，在 reader 与 producer 启动前执行，不包含 MCL_FUTURE。

locked 的回收请求返回 errno22，说明驻留防止该页面被回收，不能描述为两组均成功回收后的性能对比。锁定 151404 KiB，两次启动调用分别耗时 1887.558 / 60.006 ms；这些开销发生在设备启动之前，不计入运行时延迟。两组均未复现 >100 ms 或历史秒级停顿。

四组 exit0、原始审计序号连续、无队列丢弃或写盘错误，退出 VmLck=0，资源空且 CAN 计数不变。原始日志、SHA 与验证结果见 [code-faults-v209/comparison.json](evidence/code-faults-v209/comparison.json)。

## 候选实现与范围

新增启动选项 `memory_residency=off|current`，默认 off。current 在导入／堆预热之后、打开设备之前调用 Linux 驻留接口；检查本进程无既有锁、VmSize 不超过 350 MiB 与现有 memlock 限额，并为系统保留至少 512 MiB 可用内存。不提高权限限额，不改变全局 VM，不锁定未来分配。

锁定失败、回读失败均在设备启动前退出并释放本次锁；正常及异常退出同样释放。网关能力返回实际 locked_bytes 和启动耗时，启动器要求与请求模式相符，不能用布尔 true 冒充字节数。不宣称硬实时。

专项 45 通过；最终后端完整回归 619 通过、7 平台条件跳过。未改前端及控制算法，未重复无关前端构建。

## 正式候选集成（v210）

独立部署 `20261009-150917-95d717c9`，显式选择 current。实际启动锁定 157417472 字节，耗时 797.134 ms；运行中回读 VmLck 153728 KiB，与启动回读一致。它不包含后续新增的映射和分配，不锁定相机、ROS 或封存进程。

全会话 634.816 秒，77568 个原始 SDK 帧逐帧读回有效、无缺号，全部 Mode5 / Enable1 / Error0 / Collision0。机械臂运动、Stop、CAN 发送均为零。约 73.266 秒静止片段 `20261009T071057Z_5b1352eb` 保存 1446 周期、1459 采图样本、2918 原图、8937 SDK，319998049 字节原包完整回传，逐帧 RGB / 深度关联失效均为零，PC 与 X5 保存确认完成。该片段不含动作，不能算实机遥操作示教资格。

595.218 秒 perf 捕获只有独立封存子进程的 17 个 major fault，网关为零。四环实际仅保留最后 266.248 秒、32457 个唯一匹配帧，时钟区间宽度约 0.0325 ms；该覆盖内网口到接收上界 P95 3.304 / max 13.123 ms。全场事件日志仍记录两次 64.306 / 66.684 ms 接收等待，没有附近缺页事件，两窗早于保留的 TCP 环，无法进一步归因线路或调度。没有 ≥100 ms 接收事件，不能据此宣称所有历史秒级停顿根治。perf 67642 次 wakeup，proc 采样 max 13.180 ms，诊断扰动仍存在。

回传完成后经正式页面显式准备，基座 Z 正反方向各 100 ms、0.8 倍与 fine25% 影子输入生成四个候选；原始输入、反馈、父候选和方向审计通过。此项只证明候选链路，实际设备静止。随后截图附近出现一次 `preview_stale` 暂挂：首个记录中 X5 相机 valid、年龄 87.970 ms，E6 反馈年龄 8.765 ms。页面显示画面暂未更新、解码丢帧增加；截图与故障有时间邻近关系，未证明因果。显式重新准备成功，再显式停止成功，无服务重启。该异常保留为浏览器预览链路待分析项，不能写成全场无故障。

启动器及 X5 正常退出，网关／相机 exit0，自有监听、设备、C++／ROS／proc 资源释放；MediaMTX 由已有终止流程回收、exit1，如实保留。CAN DOWN / RXTX196367 未增，原使能不变。诊断临时文件逐 SHA 校验后释放。证据见 [feedback-faults-v210](evidence/feedback-faults-v210/) 与 [live-jazzy-v210](evidence/live-jazzy-v210/)。
