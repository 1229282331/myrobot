# 原生活动输入平滑：v130–v135

2026-10-08。开发资格记录，完整平台未交付。固定 phosphobot 正式页面、官方 Dobot SDK 和 Ruckig 0.19.4；没有自写逆解或轨迹优化器。

## 实现与边界

启动固定 `native_smoothing=ruckig`，与原生 ServoP/ServoJ 配合。使用上游 `ControlInterface.Velocity`、`Synchronization.Time`，二阶加速度限制为每通道档位速度的 5 倍，零到满幅约 200 ms。有限 jerk 的初始离线方案在连续转向时出现 31.613 mm/s 对 30 mm/s 请求，未部署；改用上游二阶接口，并在三档笛卡尔/关节随机转向的完整轨迹内检查速度包络。这里不宣称限制控制器内部关节加速度。

正常释放、回中、失联和故障仍立即 Stop，丢弃轨迹余量；在途 ACK 不确定时不推进平滑器、不追赶。Cartesian 使用四元数，未知关节目标保持 null。每步保存输入来源、前一速度/加速度、请求速度和采用增量，独立分析器用固定 Ruckig 重算。

最初专项 95 通过/1 失败：测试错误地要求仍在 250 ms 有效期内的输入不执行。修正测试时间后 96 通过；完整 425 通过/4 POSIX skip。后续最小 Stop 探针扩展 14 专项通过。失败均保留，不改生产有效期。

### t50 的停止异常

v132 输入 seq2879，tool Rx+ 最终候选 +2.04695°；Stop时实际约 +1.47191°，其后约 −1.46575°。最后 ServoP 写完距 Stop 写完仅 0.588ms，ServoP ACK 在 Stop 发送后收到，两个确切回复均保留；没有后续应用运动命令。原反馈的控制器 QTarget 明显反向，实际 J4/J5 的停止后偏移约 3.257°/3.519°。至少25ms差分得到约80/92°/s的局部平均速度，不冒称瞬时峰值。

无报警不等于停止合格；固件因果未建立，不再原样重做5°/s t50。最初分析误包含下一次输入，错误输出 `first-analysis-included-next-input.json` 保留；修正后严格截在下一活动输入前，异常仍存在。

### t100 对照

独立探针只把 t 改到100ms，保持20Hz/ahead50/gain500；随后正式页 v135 单段±5°/s实际约 +2.318/−2.276°，候选约 +2.292/−2.291°。五组停止后关节平均速度及方向均有逐帧记录，没有复现v132的大反向跳变；这不是证明该现象永远消失。

v135 Stop发送P95/max4.613/4.754ms；原0.01°峰峰/250ms窗口P95/max1004.474/1029.637ms，**仍超用户1秒目标**。Rx持续输入完整中间相位约4.47–4.87°/s，对请求5°/s偏慢；Z约8.12–9.10mm/s，对请求10mm/s偏慢。首尾半相位和全部速度均保留。Z净偏移−3.428mm，不称精确回原位。网页至首动P95区间274.718–314.417ms，未通过200ms，不能从5组估计长期分布。

空闲时出现一次 preview_stale 暂挂，采集源仍健康；核对新画面后显式重新准备，所以本会话有两次准备，不能合并成单个基准。原事件保留，未经诊断不归因无线。
