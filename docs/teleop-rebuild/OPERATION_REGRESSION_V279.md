# v279 操作缓慢与自动暂停修复

2026-10-17。完整 Goal 保持 paused。本轮针对用户操作回归修复，不改变模型、碰撞阈值或机械臂运动参数。

## 诊断与修改

1. 原 v278 会话 545 个已确认臂指令全部为接近减速（Servo status 4），没有几何预算拒绝。前 537 个指令夹爪 raw=-1：会话重启后的夹爪尚未初始化，却可准备机械臂。全行程回退包络与 Link2 的模型距离仅约 0.457–0.510 mm；同姿态 CAN raw89 约 9.76–9.80 mm，raw153 约 8.52–8.61 mm。这是准备流程缺陷；不是现场实物间隙测量，也不是本轮几何计算再次超时。
2. 5 次 input_stale 暂停期间输入持续到达，但它们回显的下行状态时间戳超过 250 ms。原算法把状态往返年龄当成输入年龄。现在使用同一控制连接的四时间戳交换，保留上下行不对称的完整时钟偏差区间，以保守上界证明输入不超过 250 ms；最近校准限 3 s，漂移余量 1000 ppm+0.001 ms。没有有效校准仍使用原服务器发出的 echo。输入接收看门狗 250 ms、失效停止、显式恢复、所有权及释放规则不变。
3. 调查后段还出现真实无线重传及连接关闭：控制 SSH 积压约 85 KB、视频约 264 KB；RDK wlan0 2.4 GHz、RSSI -28 dBm、72.2 Mbps，省电开启。关闭省电作为低延迟配置，会话退出恢复其原值。不将其称为所有断连的唯一根因，也不放宽网络或运动超时。

动态模型夹爪未知时，前后端现在均提示先初始化；不自动初始化或准备。已准备且模型减速时，固定状态区显示 `Model clearance · reduced speed`。不添加控制连接或改动布局高度。

会话 Wi-Fi 策略在执行器启动前应用、子进程释放后恢复；读写限时和回读校验。未选择配置时不操作无线接口。同步模型资产使用 Paramiko 原生流水写入，文件关闭收完确认后才写发布清单；X5 仍逐哈希校验。
