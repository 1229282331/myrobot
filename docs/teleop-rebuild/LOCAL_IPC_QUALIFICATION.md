# 官方 C++ 桥接本地传递优化（v180）

日期：2026-10-09。范围：X5 上的独立虚拟 plant；没有连接 E6、相机或发送 CAN。本轮不是实机响应、速度或完整交付资格。

## 假设与改变

v179 中计算约 3.7 ms，但计算完成至 host 记录约 8 ms。原 host 每 5 ms 轮询；C++ worker 每 2 ms 序列化重复状态。假设这些等待和重复工作贡献了部分延迟。

仅更改 C++ 桥接本地 IPC：

- host 使用标准 POSIX `select` 等待新结果，最多等 5 ms；默认 ROS 路径保持原逻辑。
- worker 等待 host 或官方 C++ 子进程可读，最多 5 ms，且不跨过下一次 20 Hz 计算时间。
- 状态变化立即发布，未变化状态按 50 ms 心跳发布。释放、过期、错误、新候选不等心跳。原部分写入先完成，后面只保留最新替代。
- 静态 profile 描述只构造一次。原反馈 100 ms、输入 250 ms、计算 50 ms期限、唯一消费、epoch、模型检查及停止不变。

未更改官方二进制、运动参数、求解器、平滑器、目标速度或实机包络。实机仍只允许已经实际走过的局部路线，不以新基准累计扩张。
