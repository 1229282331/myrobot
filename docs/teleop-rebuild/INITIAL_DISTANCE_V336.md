# v336 初始自距离查询复用诊断

2026-10-20，PC WSL隔离诊断已完成。没有改生产源码、模型、ACM、截止或设备状态，没有RDK控制owner。

## 动机与实验

v335 FIFO-b candidate567即使Servo阶段没有主线程非自愿切换，仍耗尽退离预算。其中初始自距离查询约8.76ms、退离约22.62ms，不能仅靠主线程优先级解决。

检查能否将v328 D已经用于完整退离证明的`SweepDistanceCertificate`查询加速复用于初始自距离阶段。它复用官方MoveIt/FCL几何转换、原三角形BVH与表面见证搜索上界，仍做精确FCL查询。对于盒子会使用其等价三角形表面，因而必须验证数值差异，不能假设与原mesh/box GJK输出一致。

对照保留原模型、原ACM、原0.01m查询阈值及相同的当前姿态包围盒筛选。原路径为MoveIt `distanceSelf` 的SINGLE查询并开启nearest points；实验路径为现有表面引擎、有界精确查询。交替执行顺序，分别记录顺序与并行变体。本轮只比较距离与耗时，没有把结果接入Servo或运动许可。

输入取自v335四组实际隔离请求中的慢帧及稀疏普通帧，再追加开度扫描、随机姿态和逆序姿态以改变预热种子，共574行。先用原碰撞检查剔除32个相交姿态；它们不属于此次无碰撞距离等价结论。

## 结果

第一轮检查全局最小距离，第二轮追加两向近距离pair检查，均退出0：

- 542个无碰撞姿态全局最小距离一致，最大误差`5.898059818321144e-17 m`。
- 第二轮344个原查询范围内pair的距离一致，没有遗漏或新增范围内pair。
- 第二轮顺序查询270行平均耗时390.453→303.361微秒，约减少22.3%；P95 945.045→696.251微秒。
- 第二轮并行查询272行平均398.225→358.303微秒。普通姿态并行中位反而更慢，不能只展示平均收益；当前优先考虑顺序初始查询。

这些是PC结果，不能换算成RDK延迟承诺，不能证明已解决v335的退离降速或旧281ms停顿。试验没有验证所有模型变更、padding/scale、attached body、条件ACM、世界障碍或nearest-point消费者，也没有完成原生整链路回归。
