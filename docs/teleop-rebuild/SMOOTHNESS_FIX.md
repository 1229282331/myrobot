# v234 连续输入跨步修正

2026-10-10。针对用户“运动卡卡的”后的修复任务。完整平台 Goal 仍暂停。本次修正已部署，正式网页键盘与合成手柄均完成实机小幅验证；不宣称所有速度、所有姿态或整个平台已通过最终验收。

## 改动

沿用固定 phosphobot 页面、官方 MoveIt 2.12.4 C++ 求解器／平滑器及 Dobot SDK。未改 ServoJ(t=0.1,aheadtime=50,gain=500)、TCP、关节限位或控制器参数。

1. CppCycle 统一管理 50 ms 目标生成周期。网关在新候选可用时消费，移除第二套“距上次发送满50 ms”的等待；重复候选仍只能消费一次。快速释放／再按也受生产者周期约束，延迟不产生补发或追赶。
2. 在原50 mm TCP平移球附近逐渐减少向外的径向速度，保留向内、切向及旋转分量。采用明确记录的速度阻尼，不另写IK或轨迹优化器。原硬边界检查仍在；没有扩大工作区。原始输入、有效输入及减速依据分别保存，审计可重算。
3. 保持释放／断连停止、原始反馈新鲜度、设备报警及单在途命令规则。没有以放宽保护来掩盖跨步。

## 限制与回归

- 发送节拍仍有抖动，键盘最小22.611 ms、手柄最小26.477 ms；消除跨步不等于硬实时或零速度波动。生产者周期约50.24 ms，而IPC到达和网关发送仍引入抖动。若试用仍有可感卡顿，下一项应定位这段调度，不能再次靠放宽边界处理。
- 边界阻尼通过离线连续逼近／反向退出／工具坐标及来源审计测试，本次没有让实机走到50 mm边缘，不冒称物理边界实测。
- 此次只验证基座Rx小幅旋转；不外推全范围、10°/s或实体手柄体验。普通档参数仍30 mm/s、10°/s，用户已有手动范围设置保持。
- 后端完整694通过、8跳过；专项229通过。最初两次新增夹具／旧预期失败及修正后结果均保留在output。前端本次未修改，沿用v232正式构建与既有128项结果，不冒称重新构建或全功能复测。
- 试验结束后正常释放测试会话，重新启动关闭合成输入的operator会话。页面恢复实体手柄，保持未准备；普通退出保持机械臂原使能。
