## 接收空档的诊断修正

v319 退休日志有143.906 ms接收空档。前后设备 TimeStamp 相差145 ms，RunTime 未变；附近224原帧保存于 `evidence/j5-direct-v319/feedback-gap-review-v320.json`。没有据此证明网络无丢包；应用日志序号连续只证明日志自身未丢条目。
