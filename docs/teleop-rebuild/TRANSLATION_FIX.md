# 平移方向与发送节拍修正 — v245

2026-10-12。本轮只处理用户报告的平移方向不稳、运动卡顿；完整 Goal 保持 paused。已发布到正式工作台，不能据此称完整平台或全速度验收完成。

## 修正

1. `workspace_velocity.py` 将触边径向投影改为对原输入向量统一缩放。原来单轴 −Y 指令可能产生 +X、+Z；现在只降低原方向的速度，零轴保持零。向内退回立即可用，基座／工具坐标一致，纯旋转不变。50 mm 球形范围和硬边界不变。
2. `feedback.py` 缓存当前不可变原始帧的官方 SDK 精简解析，复用同帧解析结果；返回值复制可变成员。接收线程不参与解析，也不等待消费者缓存锁；新鲜度仍使用本帧原接收时间。
3. 工作区及静止检测中的微小 NumPy 运算换成等价标量运算，保留原阈值和判定。
4. 新增标准 Linux 会话级 CPU governor 管理。`workstation.json` 显式使用 `performance`，维持系统原 1.5 GHz 上限，不改频率上下限、温控或开机配置。取得本项目锁、检查旧资源后才切换；自有子进程退出后恢复原 governor。部分启动失败可恢复；外部更改不被覆盖，未退出的自有子进程不会被当作清理成功。

控制意图、输入映射、ServoJ `t=0.1/aheadtime=50/gain=500`、20 Hz 生产周期、TCP 150.4 mm、官方关节两端各留 5°、v236 方向奇异恢复二进制均未修改。没有新前端代码，本轮沿用已构建的官方 UI。
