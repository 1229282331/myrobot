# 独立使能与准备流程验收

2026-10-07，v42。**正式页面的软件流程已通过设备替身验证；真实 E6 使能尚未执行，本报告不授予实机运动资格。**

## 改变与用途

此前未使能机械臂无法从工作台进入操作，需要开发脚本。现在在保留的 phosphobot 控制页添加独立使能操作，经正式输入连接、单控制所有者与官方 SDK 的无参数 `EnableRobot()` 发送。启动、重连和准备均不自动使能。真实设备状态只来自独立反馈线程。

发送前核对回中、序号和新鲜度、未使能空闲、报警/碰撞、实际静止、零偏移 User0/Tool0、画面、控制连接及录制状态。同一会话只提交一次使能，不重试不确定命令。该独立操作允许10秒回包时间；Servo的0.2秒与Stop的1.5秒回包期限未改变。

接受回包后重新收集至少5秒已使能稳定反馈。未使能的静止时间、旧连接代次及旧模式时间不计入。完成后仍由操作者明确准备；期间准备与夹爪初始化被拒绝。退出收集在途使能回执，不发送补偿性的 DisableRobot。
