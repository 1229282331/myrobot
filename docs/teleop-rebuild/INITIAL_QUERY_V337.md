2026-10-20。本轮有隔离候选实现、编译和验证进展。正式运行版本仍为 `90fe4ad1`，模型 `3b4003e4`、配置 `d44b3403`、原碰撞规则与截止保持。没有启动平台 owner、访问设备执行口或执行实机动作；没有 Git 提交。完整遥操作目标仍未完成。

## 现有问题与本轮范围

v335 带相机负载的调度 ABBA 仍失败：2154 次合成写入中存在两次暂停，以及一次退离预算耗尽后的极低倍率写入。提高主线程调度优先级并未消除全部失败，旧约 281 ms 长停顿也未定位完成。不能将连接恢复、低速单关节通过或本轮 PC 结果当作中高速系统验收。

本轮将 D 候选已有的精确表面距离查询用于初始自距离，减少重复的 FCL 搜索。独立源在 `output/initial-query-v337/source`，可复现准备入口为 `output/prepare_initial_query_337.py`，四文件补丁和源哈希在同目录上级。本轮没有混入 FIFO 调度修改。

保留原始实际碰撞检查和当前姿态的包围盒排除。仅支持原 FCL 环境、零 padding、单位 scale、无 attached body、无世界物体及无有效条件 ACM 的场景；其他情况使用原查询。旧三角形索引仅在当前姿态重新计算搜索上界，不缓存旧姿态距离作为运动许可。

新增可选最近点输出，各形状查询只写自己的结果槽，汇总发生在查询全部结束后。预处理点从形状 A 坐标转换到世界坐标，原生 FCL 查询点保持世界坐标；整理回原近距离缓存及 link-local 最近点，供退离查询排序使用。

## 性能与限制

本轮测量的是完整 collision monitor，包含真实碰撞检查、筛选和最近点整理。它不同于 v336 的单一距离查询计时。

| PC 用例 | 原均值 → 候选均值 | 原 P95 → 候选 P95 |
| --- | --- | --- |
| 第一组 542 个可优化姿态 | 599.216 → 511.890 µs，约减少 14.6% | 1176.190 → 949.236 µs |
| 密集组 2108 个可优化姿态 | 668.752 → 635.511 µs，约减少 5.0% | 835.574 → 801.061 µs |

各姿态有单次计时长尾，候选也有比旧查询慢的点，不能用最大值差异声称消除调度长尾。完整退离阶段均值 1656.08 → 1649.48 µs，基本相近；本次优化目标是其之前的初始查询，不是整条控制链路翻倍提速。完整散点图 `evidence/initial-query-v337/pc-monitor-timing.png` 已查看。
