# 连续换向与实机跟随：v87–v89

2026-10-08。基于 e5561bb。完整平台仍未交付。正常释放的稳定窗口上限保持用户指定的 **1 秒**，收到释放立即请求 Stop。本轮没有调整尾差标准、控制器参数或工作区限制。

## 发现与修改

正式 phosphobot 键盘页新增受限连续输入验收：平移每向1秒、旋转/关节每向0.5秒，六次往返，全程保持 Space，最后释放。它生成 DOM 键盘事件，经原页面映射、PC、无线、X5、官方 ServoJ；不生成机器人目标。按钮只在 acceptance_inputs 启用。

v87 首轮 X 影子运行暴露一个输入问题：每次换向先 keyup 再 keydown，原即时发送把中间零向量发到 X5。11段零向量分别持续约1–19ms，207候选跨9个epoch，间隔最大255.450ms；另触及初始关节包络。它不是合格的连续运行，原记录完整保留。

现在仅把仍按住 Space 时的方向 keyup 采样推迟到当前 JavaScript 任务的 microtask checkpoint；同任务的新 keydown 使它失效并发送最终键集。单独方向释放不等20Hz周期，Space释放仍同步。Esc、失焦、源卸载取消待处理采样；没有定时延迟、放宽新鲜度或补发历史输入。

24项初始前端测试保留；修正后29项及正式构建通过。v89后又使**自动验收按钮**在边界提示出现时取消剩余往返，避免一个已失败序列继续后面的相位；30项前端及最终构建通过。这个最后的自动取消改动只有DOM专项验证，未冒称在v89实测过。普通操作员仍可回中后向可行方向退回。

## v88 影子复核

- Y方向12.012秒，235候选，单一epoch，无零向量夹入、无边界事件。候选最大位移28.161mm、关节9.218°；各相位中段候选速度29.649–30.334mm/s。
- Rz方向5.951秒，116候选，单一epoch，无零向量夹入。0.5秒反向周期受加减速瞬态影响，反向阶段的平均候选速度未全部转负；**不称10°/s连续旋转通过**。
- 18233原SDK帧全部有效、无缺号/报警/碰撞，运动/Stop/CAN均0。来源及完整平滑窗口审计错误0。

原 `audit_moveit_page.py` 的方向算法比较“候选减静止实机位置”，在连续反向时可能仍是正位移，所以该旧方向汇总显示false，原结果保留。新增只读 `analyze_continuous_input.py` 按完整输入相位报告相邻目标变化、实际反馈斜率和所有零输入，不把候选当实际运动，也不删除加减速阶段。所列中段斜率明确排除首350ms/末100ms，单独保留全相位斜率。

## v89 实机结果

同一正式页面先fine25%（7.5mm/s），再普通30mm/s。没有重新使能或初始化夹爪。

| 项目 | 7.5mm/s连续Y往返 | 30mm/s连续Y往返 |
|---|---:|---:|
| 按住输入 | 12.016秒 | 12.017秒 |
| ServoJ发送/确认 | 223/223 | 67/67 |
| 连续轨迹epoch | 1 | 3，边界Stop后重新产生候选 |
| 中途Stop | 0 | 3 |
| 实际位移最大 | 8.001mm | 39.256mm |
| 释放→Stop发送 | 18.017ms | 已提前停止，不是正常释放试验 |
| 释放→250ms静止窗口起点 | 705.309ms | 不计作正常释放验收 |
| 释放后法兰位移 | 0.578mm | 已提前停止，另存原值 |
| 首次Stop前最大J4实际/内部目标差 | 0.219° | **3.813°** |

fine十二相位中段实际投影速度7.353–8.081mm/s，每段方向正确；最后位置相对起点Y为−0.622mm，不能说精确回到起点。候选方向/控制会话连续，正常释放符合1秒。

普通档第一正向阶段中段实际Y为29.361mm/s，但随即出现明显关节跟随差，**整组失败**。首个Stop发生在输入后1.212秒；此之前J4内部目标与实际差已达到3.813°（原反馈序号16906）。此段候选姿态基本保持，而实际姿态已经偏移，之后边界Stop和新候选种子继续保留了偏移。最终相对普通档起点位移约[−4.462,+36.389,+10.243]mm。不能归为1秒尾差，不能仅凭单个达速片段宣布30mm/s通过。

首Stop前指令发送间隔P50/P95/max=51.894/87.506/88.743ms；没有长达数秒的输入断流。该结果定位到实际跟随环节，但**尚未证明具体固件、控制周期、ServoJ参数或物理原因**。不把控制器Error0当作实际跟随正常，也不盲目提高gain或放宽包络。

全会话24805原SDK帧有效、缺号0；所有290 ServoJ与4 Stop确认，Error0/Collision0；CAN0。来源审计错误0。`fine-y-moving`快照的文件标签取名早于回读，实际拍摄时已经结束且静止，不能当运动中画面。
