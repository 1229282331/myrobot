# v338 控制断线后的只读视图与显式恢复

2026-10-20。正式前端源已修改，独立构建通过；尚未发布到正式服务。真实相机和控制链路的整体验收仍待完成。

## 问题和行为

原页面的 HTTP 状态可能已经恢复，但控制 WebSocket 仍然关闭；Prepare 在重新建立连接前先检查视频，因此视频未恢复时可能无法重连。另一个问题是延迟到达的 HTTP capabilities 可以覆盖当前控制连接的能力数据。

- 共享现有 `/e6/state` 只读观察：控制连接关闭时恢复 3D 和相机地址，明确标为只读，不导入观察数据中的 `ready` 或 `echo_ns`。
- Prepare 先显式重建关闭的控制连接，再根据新状态检查视频、输入回中及其他既有条件。条件不满足时，不等待以后自动准备。
- 当前控制 WebSocket 的状态和能力优先于 HTTP 发现结果。
- 断线立即清除旧输入、准备请求和连接提示。浏览器实测发现的第二次断线残留“已连接”提示已修正。

正式文件：`teleop-platform/frontend/{WorkbenchChrome.tsx,useE6Control.ts,ControlStatus.tsx}`；回归：`teleop-platform/frontend-tests/control-recovery.test.tsx`。
