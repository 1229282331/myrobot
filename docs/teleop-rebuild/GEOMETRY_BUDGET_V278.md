# v278：几何检查耗时优化与预算调整

2026-10-17，最终候选C已完成隔离验证、发布及在线静止核对。完整Goal继续暂停。

## 修改

`SweepDistanceCertificate::distances`继续复用MoveIt AABB。世界坐标的快速距离下界不足以排除时，再分别在两个部件的局部刚体坐标系中计算包围盒距离下界，取三个坐标系中最大的有效下界。只有下界严格超过整个候选区间的运动上界时，才省略该部件对的精确FCL距离查询。旋转导致世界轴包围盒变大/重叠时，因此可以避免不必要的精确查询。

每个盒仍覆盖该部件的全部碰撞形状；在任一正交坐标系中的包围盒距离都是形状真实距离的下界，多个下界取最大仍为下界。无法证明分离的部件对继续用原FCL与原碰撞矩阵。模型、5mm几何余量、1mm扫掠间距、40mm最大扫掠长度、附件碰撞排除均不改变。不缓存历史姿态或许可。

两轮X5组合测试未通过后，已做最小复现重新评估。剩余失败只涉及`Link2/op_hand_wide3_Link`及部分`Link2/op_hand_wide_loop_Link`，不是可豁免的夹爪内部固定关系。每区间仍需54–72个采样点；虽然只剩1–2对部件，旧路径每点仍调用整臂`PlanningScene::checkSelfCollision`。上一候选的同区间臂内不变量复用已撤回。

当前第三版改为复用MoveIt原生`createCollisionGeometry`、FCL对象AABB重叠检查及MoveIt原生`collisionCallback`，只给仍需检测的部件构建当前姿态的碰撞对象。每个区间只准备一次部件对列表，全部原采样点仍执行。只缓存不可变形状/BVH，不缓存位置或结果；未知开度、附加物、非默认缩放/填充、非指定组或距离请求仍回到原整臂路径。准备列表及其请求/矩阵只在本次scene只读锁内有效。

几何预算由30ms调整为35ms，并与本次C++回调起点后的42ms截止取更早者。回调结果仍必须满足既有50ms求解周期、原始输入250ms及反馈100ms截止。35/42ms是结果接受截止，不能抢占单次正在执行的FCL调用；因此新增计算后截止复查，迟到结果不会成为有效许可。可选开度邻居失败仍不撤销已独立通过的必需区间。

程序启动日志和结构化审计分别记录预算与本次实际可用预算。停止、控制所有权、柔和起步、速度、TCP151.4mm、负载0.750kg/COM(0,-14,46)mm不改变。
