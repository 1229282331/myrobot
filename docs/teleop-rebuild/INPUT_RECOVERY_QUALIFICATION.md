3. **v57即时计算**：通过会话校验的新运动输入立即提交MoveIt；不等下一个设备tick才开始计算。receive不发ServoJ，发送仍由20Hz tick检查并执行。释放清空候选epoch；未准备、无效、重复、停止待确认、健康异常等不能提前启动计算。62专项、203完整后端通过/4 POSIX跳过；正式影子212候选12方向来源通过、18339原包有效，运动/Stop/CAN0。

5. **v59丢弃过期包**：过期包不替换、不续期已有有效输入；原输入超过250ms仍停止。释放即使echo过期也立即清除运动意图并停止。新鲜输入可在原有效期内正常接替；真正失联仍需回中并重新准备。增加独立intent_sequence，把已采用输入与最高已见序号分开，避免丢弃包污染候选来源。66专项、207完整后端通过/4 POSIX跳过。正式影子214候选12方向/19409原包通过，运动/Stop/CAN0。
