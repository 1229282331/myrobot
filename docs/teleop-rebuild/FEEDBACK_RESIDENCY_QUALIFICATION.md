# v205 反馈线程与内存驻留对照

本次没有连接或操作 E6、相机、CAN。四组均正常退出，完整审计、下载 SHA 和内存解锁已核对。结果不足以证明锁内存能解决历史秒级停顿，未将它加入生产配置。

## 假设与方法

v200 曾记录到反馈等待与文件页面调入重叠；v203 的约 1.2 秒停顿发生在录制／封存开始之前。因此用独立测试进程检查：在 SD 顺序读取负载下，当前映射页驻留是否减少反馈接收延迟。

采用已部署的 v203 release `20261009-131626-9f88c2cf`，运行实际 `FeedbackReader`、`Audit` 和 `NativeExecutor` 的 idle `tick/state`。没有调用执行器 `start()`；唯一数据源是一次性 socketpair，地址校验限定为 `synthetic-only:30004`。独立标准库子进程约 125 Hz 回放一个历史 1440 字节 SDK 帧，仅把设备时间戳替换为同机单调发送时刻。接收延迟以同一 X5 时钟计算，不涉及主机间时钟相减。

每组独立子进程顺序读取四个旧 ZIP 两遍并计算 SHA，读取内容一致。顺序为 default／locked／locked／default；没有清缓存、改变系统调度器或更改其他进程。locked 只调用本测试进程的 `mlockall(MCL_CURRENT)`，在测量开始之前完成，结束时 `munlockall()`。这不等于锁定将来分配的所有页面，也不代表实时调度保证。[接口语义](https://man7.org/linux/man-pages/man2/mlockall.2.html)

## 结果

下表只统计读取负载窗口，完整开始／退出事件另存，未把锁定调用时间藏进“接收零延迟”。

| 顺序／模式 | 负载时长 s | 接收帧数 | 接收 P95 ms | P99 ms | 最大 ms | 测量段 major faults |
|---|---:|---:|---:|---:|---:|---:|
| 1 default | 59.649 | 7335 | 0.561 | 2.140 | 19.282 | 3 |
| 2 locked | 38.746 | 4766 | 0.268 | 1.636 | 5.741 | 0 |
| 3 locked | 34.236 | 4203 | 0.179 | 1.473 | 3.276 | 0 |
| 4 default | 33.472 | 4120 | 0.355 | 1.549 | 5.129 | 0 |

四组读取窗口均无超过 50 ms 的接收样本；循环调用最大间隔分别约 51.101、51.113、50.637、51.259 ms。第二、三组锁定约 292 MiB，锁定调用分别耗时 **1641.707 ms、91.471 ms**。第一个默认组启动／退出有慢接收事件，保留在 `receiver-events.json`，不能用测量窗口统计冒称完整生命周期都低于 50 ms。

四组全部 SDK 原字节审计条数为 8107、5717、4959、4857；序号连续、写入摘要计数一致。生产者／读取进程退出码均 0，订阅丢弃 0，audit error 为空。各进程退出前 `VmLck=0`；实验结束无设备连接、相机占用、控制／计算进程或自有 proc 挂载，CAN DOWN、RX/TX 196367 未增加。完整明细及文件 SHA 在 `evidence/feedback-wait-v205/`。

## 决策与局限

默认末组也没有 major fault，负载时长随顺序下降，说明缓存状态不可忽略。该简化负载没有完整网关、MoveIt、真实视频或无线传输，没有复现 v203 的秒级停顿；不能把 ABBA 的有限改善视为根因证明，也不能将 mlock 调用直接插入运行中的控制会话。

不改生产内存锁定、反馈期限或运动参数。下一实验回到正式 shadow 页面＋真实静止反馈＋视频＋录制，采集线侧时间和独立系统等待记录；期间不并发归档历史大文件。只有新证据支持的针对性改变才进入后续实机验证。实机范围始终受 PLAN 中已经走过的局部路线及线缆约束限制。

执行源：`teleop-platform/scripts/qualify_feedback_residency.py`。部署 SHA、固定来源清单、preflight、原帧审计、各组 metrics／exit、资源核查和结论分别见证据目录的 `deployment.json`、`audit-download.json`、`comparison.json`、`post-resources.json`。v204 的录制拒绝提示未参与该 idle 对照，不能称 v204 完整平台对照。
