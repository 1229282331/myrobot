# v316 J5 发送节拍修复与 SDK 对照

2026-10-20。发送时序和跟随误判修复已发布，完成软件检查、官方 SDK 实机参考以及正式网页局部低速回归。本轮没有复现历史的大幅停滞、突跳或跟随异常停止；发送节拍仍有波动，不能据此称所有速度、姿态和模式均无抖动。完整 Goal 保持暂停，自主抓杯已取消。

## 已确认的问题与修改

v315 原会话 5622 对连续指令的求解周期为 50.00–57.50 ms，实际发送间隔为 14.03–108.49 ms；存在 10 次跳过未发送父候选及 4 次取出时有效、实际写入时已过期。v314 五次固定 2° 最新候选领先检查把正常运动误判为关节跟随异常；另有两次先取时间后读反馈引起的负年龄。137820 原 SDK 帧没有序号或时钟回退，因此没有手动校时或零位校准的依据。

本次仅改七个 Python 源文件：joint_tracking.py、dashboard.py、gateway.py、jazzy_cpp_worker.py、moveit_bridge.py、jazzy_host.py、cpp_cycle.py。

- 求解器最多领先一个候选，收到该候选实际发送回执后才继续推进。写口距上次实际发送至少 50 ms，迟发后不追赶、不跳过未执行父节点。
- 写入前按原始有效期重新核对反馈、夹爪几何与连续性；底层事务锁内再次检查截止时间。过期候选不发送，停止后须中立输入重新开始。
- 2° 硬跟随界使用同帧控制器目标与编码器。另以最近 250 ms 实际发送轨迹范围检查执行滞后。原真实停滞、持续误差、相邻实际写入突跳保护保留。
- 不调整模型、ACM、关节范围、负载定义、TCP、设备碰撞检测、100/250 ms 新鲜度、42/50 ms 计算预算及控制所有权规则。

原生二进制保持 v299 `6314bdc0ff22586fc42c5be4e38b96a5f0e54380e9fd5e27e1a44a6785a94633`，模型 `3b4003e4…`，安装 B，TCP 151.4 mm。没有编译或发布工作区中的实验 C++ 候选。

## 软件验证

完整后端 **1141 通过、8 跳过**。五个旧误停窗口共 604 原帧通过；两个负年龄事件覆盖，真正过期仍被拒绝；v304 两次真实不跟随仍在相同时间、相同原因被拦截。测试包含停滞、突跳、过期写口、父链丢失、换向、首次候选取消与释放重启。

RDK 使用正式原生求解器、IPC、写口和双审计进程，设备由延迟 150 ms 的合成反馈替代，网络隔离为 loopback。关节、旋转、工具坐标、当前姿态关节与位移测试均无跳点、过期发送或跟随停止；注入 65 ms 主线程停顿时按原截止产生六次预期暂停，中立后恢复。这是软件链路资格检查，不是机械动力学仿真。

当前姿态关节测试 494 次发送，间隔最小/中位/P95/最大 52.78/55.87/58.08/64.10 ms，标准差 1.64 ms。实际节拍约 18 Hz，不能称精确 20 Hz。正式平台实机结果见下文。

## 官方 SDK 实机参考

用户已确认断开官方软件连接，沿用低速测试授权。新静止反馈及 RGB 已核对。机械臂地址 192.168.1.4，RDK 192.168.1.13；RDK 经 wlan0 访问路由器上的机械臂。没有与平台同时控制。

新回读发现重心为零；独立持锁下官方 SetPayload(0.750,0,-14,46) 一次成功，856 帧无报警且最大关节变化 0.007553°。夹爪仅观察，raw29，无位置命令。

原普通模型对 J5 中心 ±2° 做 320 个连续小区间证明，开度 raw28–30；全部 ordinary_path，无退离豁免。SDK pilotC 用同一 ServoJ 参数 t=0.1、aheadtime=50、gain=500，低速五次平滑曲线完成 ±1.5° 往返并返回起点：

- 601 条 ServoJ 全部 0 回包，Stop 一次成功。
- 6645 原 SDK 帧连续，无设备报警或碰撞。
- J5 同帧最大跟随误差 0.048622°；其他关节最大峰峰值 0.015106°。
- 实际写入间隔中位 56.72 ms、P95 63.27 ms、最大 71.65 ms。

这支持当前姿态低速下设备能正常跟随；没有证明所有工况正常，也不能单独关闭 v304 初始不跟随的根因调查。SDK 曲线与平台键盘输入的速度波形不同，不冒充完全同轨迹 A/B。

失败原件保留：pilot 的触发文件打开模式错误，零运动；pilotB 在 156 条均确认后因测试器同步相机状态 IO 超过原图像新鲜度而停止，Stop 回包超时未称成功。随后独立只读 852 帧确认静止。测试器改用既有异步 CameraOutputs，Stop 采用生产 1.5 s 回包期限，得到上述 pilotC 结果；未放宽视频 500 ms 新鲜度。
