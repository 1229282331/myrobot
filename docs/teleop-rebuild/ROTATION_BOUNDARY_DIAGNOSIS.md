# 用户旋转试用卡顿：边界反复启停

2026-10-09，v231。用户报告卡顿、跳动或松开后仍动，并明确要求放宽限制，由本人测试旋转，本轮不再以线缆长度约束原来的极小包络。此项没有取消硬件限位、碰撞、输入失联或释放停止。

## 原始证据

v230实机会话20261009-230018-60e13b49正常停止并释放。用户实际请求9°/s，启动仍配置姿态偏离起点最多0.65°，不适合作为普通手动旋转入口。正式记录为23段活动输入、62个ServoJ全部确认、32次workspace_blocked与32次Stop全部确认。每次边界均是rotation超界；同一次持续按住曾有3次Stop。60477原始SDK帧invalid0，无Error或Collision。

旧处理每次越界调用Stop并重置求解器；实际制动落点仍在界内时，同一持续输入又生成界内的短目标，继而再撞到软件边界。形成反复启动／停止，不能归为手柄方向问题或用户错觉。v230的0.65°试验配置不应被作为一般上手入口，之前影子短脉冲没有覆盖持续撞界。

原始文件保存在X5该会话audit；本机`evidence/tcp-v231/events.jsonl.gz`保留完整事件，`feedback.npz`由固定官方MyType逐帧读取，原始文件SHA与计数在summary.json。32个边界记录、输入分段在input-stop-analysis.json。23次释放至下一活动输入之间未发现新的运动发送；观察窗口至多1秒、部分因下一输入更短，最大关节变化0.094757°。这不是完整停止资格，也不排除用户可感知收尾。

## 修改

- 到达软件测试边界后保留被阻挡方向，同方向持续按住不再次向求解器或设备推进。速度倍率改变不解除该状态；回中、释放或方向改变后仍用原工作区重新检查。会话保持，不要求重启。
- 官方MoveIt、ServoJ参数、反馈接收、停止与碰撞保护不改。本轮修复不重写轨迹求解器，不通过放大范围掩盖反复启停缺陷。
- 用户旋转测试入口姿态范围改为距新准备起点最多10°，位置外层范围50 mm给名义TCP旋转产生的法兰补偿留余量；各关节相对起点仍最多10°，厂家关节／碰撞／奇异限制可提前拒绝。不是无限旋转，也不是每个欧拉角分别允许10°。
- 主界面直接显示实际姿态范围，不再只藏在详情。沿用夹指名义TCP150.4 mm；物理标定限制保持。

## 验证及交接边界

新增替身设备回归先复现持续按住导致额外20条ServoJ；修正后同方向20周期与倍率变化都保持一次Stop，反向、回中和释放重新操作通过。首轮夹具未指定MoveIt入口而失败的XML保留；补齐fixture后取得真正的旧逻辑失败，未改判。107项专项及扩展190项控制回归通过，正式前端构建／发布成功。没有因文案变动重跑长时实机验收。

新版实机入口仅启动、读取新状态与相机，由用户准备后测试；代理未自动执行扩大后的旋转。当前成果是针对已复现软件原因的修复与用户测试版本，不宣称新的10°全部实走或完整平台交付。
