## 最终实现

- 先生成实际要发送的加速度平滑候选，再证明这一条路径；失败时恢复已提交平滑器状态，走原减速路径。避免重复证明两条不同路径，消除跟随滞后时倍率在约 0.2 与 1 之间反复切换的原因。适配限定于已检查的 `AccelerationLimitedPlugin`。
- 沿用 MoveIt / FCL 精确几何。FCL 原生 RSS 下界及当前位姿下重算的三角见证上界减少搜索；逐连杆材料点运动上界仅排除已证明整段不接近的部件对。私有 Shape clone / BVH、原生 geometry+transform 查询与预初始化碰撞对象避免并发重写共享 AABB 和重复扫描网格。固定 7 个 worker 加调用线程，收齐批次后顺序核验证书，不排队新的运动。
- 退离计算 37 ms、整个回调截止 42 ms、控制周期 50 ms。迟到或未完成证明仍拒绝。模型、碰撞排除表、余量、1 mm 采样、速度、加速度、柔和起步、TCP 和负载保持。
- 输入 250 ms 过期立即 Stop，丢弃旧输入和旧轨迹，但保留当前所有者与 Prepare。只有带暂停后新回显的中立输入才能解锁；持续按住及旧中立包都不能恢复运动。断连、失焦、换源、设备故障、主动 Stop 仍取消准备。
- 显式 Prepare 后直接按方向键或操作摇杆／扳机，不再要求 Space / LB。Shift / RB 精细控制、Escape / Back 停止保留；输入焦点隔离、释放回中、扳机死区保留。键盘释放立即发送，同一微任务合并多轴变更。
