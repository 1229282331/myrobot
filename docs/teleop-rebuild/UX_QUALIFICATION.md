## 发现与修复

1. 上游 Card 的默认留白在 720p 挤压视频；收紧 E6 作用域布局。TooltipTrigger 会覆盖按键卡的 data-slot，依据实际 DOM 修正样式选择器。页面截图照实保存，不修改输入映射。
2. URL 直接打开片段库时，输入连接可能后建立而漏掉暂停事件。用一个共享的弹窗状态补充原同步通知，连接建立时同步当前暂停状态。关闭后仍需回中与显式准备，不恢复旧输入。
3. 首批采样可能处于录制初始化，尚无此前原图，界面增加缺图说明；采样读取失败时不显示上一采样的旧图或旧关联。真实首采样缺图保留，未向前取未来图补齐。
4. 新 Recorder DOM 测试首次失败来自测试环境重复 React／路由解析，原失败日志保留；固定测试侧 react-router-dom 路径后通过，没有改生产依赖版本。
5. 离线候选审计最初按序号覆盖输入，刷新／切换连接后同号输入造成来源误报。保留初始报告；修正为在同一 X5 单调时间上查找源派发之前最新的同号收包，仍要求 250 ms 新鲜度和完整载荷一致，不按载荷搜索“能通过”的记录。4 项专项覆盖跨连接、过期／未来、矛盾载荷与空候选退出；错误或空候选现在返回非零退出码。仅修改离线审计，不改生产路径。
