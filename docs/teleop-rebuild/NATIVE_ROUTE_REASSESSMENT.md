# 原生 ServoP 路线重新评估

2026-10-08。低速对照，不是完整平台交付。

## 为什么重测

早期原生 ServoP 的 541–696 ms 停止尾部超过当时 500 ms 判据，因而进入 MoveIt 备选。用户随后接受正常释放后的 1 秒稳定窗口；当前姿态也已经远离旧 J4 约 −104° 的接触位置。重新检验原先优先路线有依据，旧失败仍按原标准保留。

共用固定 phosphobot 正式键盘页、真实映射、PC 无线连接、X5 单控制者、官方 SDK Motion.ServoP、原始反馈与相机。新增启动固定的 motion_engine 选项；默认 MoveIt 不变。原生模式不启动 ROS、不挂载其 proc、不用显示模型生成控制目标；目前仅 commissioning 2 mm/s、1°/s 可用。没有使能、清错、Continue、CAN、持久参数改动或下机操作。

原生笛卡尔候选的关节目标未知，joints_rad=null，observed_joints_rad 保存发送前的实测关节。source_input 记录采用输入及其序号和接收时间。原始 ServoP 命令、回执与实际反馈保留，现有七维动作导出器不能以观测关节替代内部 IK 结果。

## v125–v127 结果

- v125 影子：12 个正式页面方向、235 个不同候选，输入来源与相邻位移/四元数方向一致；28874 个官方原帧有效、缺号0、无报警。运动/Stop/CAN发送0。
- 初次完整回归402通过、4失败、4跳过：新增记录字段在可选Ruckig减速分支遇到已释放输入，以及测试替身缺少新增引擎回读。修正记录对释放/过期输入的表示，原始失败XML保留；完整复测407通过、4 POSIX跳过。
- v126 只启动实机服务，未准备、未发送任何动作，在回归修复前正常退出；不称其为运动试验。保留Paramiko退出时的析构器异常，独立设备/资源审计为空。

## v128 首动调度实验

假设：原生首命令的0–50 ms等待来自空闲控制周期，缩短它不需要替换SDK或修改控制器参数。新输入只唤醒控制线程，设备发送仍由该线程检查反馈/新鲜度后执行；首目标仍为一个50 ms周期增量。唤醒分支仍核对前次发送时间，常规流保持原start-to-start 20Hz调度，不追赶积压输入；实际收发抖动单独保存。连续流不反复唤醒，正常释放清除通知；按住允许动作但轴回中也正常Stop并保持会话。

93项专项、完整410通过/4 POSIX跳过。v128正式影子2个正反向、41候选来源/方向一致，13415官方原帧有效、运动/Stop/CAN0，正常退出。

v129同样2 mm/s、1°/s、t50/ahead50/gain500，从新实际状态一次准备，重复v127的12个短输入和两组12秒连续输入：601 ServoP全确认、14 Stop全确认；27240原帧有效/缺号0、全Enable1/Error0/Collision0，无暂挂、无中间Stop。实际发送间隔按每段活动输入统计，原始记录保留。

每组14样本、全部计入，首动阈值和时钟算法不变。结果支持减少本地首发等待，但网页时延上界仍超过200ms，不能宣布达标或从14样本推断长期分布。v129完整中间相位Z实际1.947–1.985 mm/s，Rz 0.900–0.961°/s，旋转仍偏慢。其余模式/高级速度/实体手柄未用这组结果替代。

下一项有效实验：保留原生直接控制器运动学与首动唤醒，复用现有Ruckig在活动输入阶段平滑加减速，正常释放仍立即Stop；先影子和低档对照，再验证10 mm/s、5°/s，不直接跳到最终30 mm/s、10°/s。默认MoveIt不因这轮低速试验自动切换。

证据：evidence/native-route-v125、live-jazzy-v125/v126/v127/v128/v129、native-route-v127、native-wake-v128/v129。含官方原始SDK帧、完整事件、执行源码ZIP/SHA、配置、静止端点与资源释放。MoveIt v124使用扩展分析器复算，原motion analysis完全一致。所有会话已正常退出，CAN DOWN/RXTX73118不变，设备/相机/ROS/挂载资源审计空，保持已有使能。

这次结果支持继续原生路线资格评估，尚未验证高档速度、加减速、多轴、完整故障/示教/夹爪、30分钟综合稳定性及最终实体手柄。默认MoveIt与原证据保留；不能把低速原生通过当作最终30 mm/s、10°/s交付。


## v130–v135 接续

原生活动输入已接入固定 Ruckig 二阶速度接口；t50 在5°/s工具Rx停止时出现控制器目标反向及实际关节跳变，失败保留。独立SDK及正式页面改为t100后未复现该大跳变，但速度、首动及一次1029.637ms稳定窗口仍未达标。具体结果、时序和限制见 [NATIVE_INPUT_SMOOTHING.md](NATIVE_INPUT_SMOOTHING.md)。这是候选测试，不是操作者交付。
