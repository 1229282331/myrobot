# 速度配置与正常边界行为验证

2026-10-07，v41。完整实机交付未完成；本轮没有 Enable、实机位移、Stop 或 CAN 发送。实机现场确认仍待回答，工作限于离线、虚拟设备和真实反馈影子。

## 改动

`motion_profiles.py` 是网页能力、PC/X5 输入检查、Jazzy 求解器关节上限的共同配置源。`Start-E6.ps1 -MotionProfile` 经 launcher、独立 X5 supervisor、gateway、隔离 ROS 子进程传递；启动完成前核对网关报告档位。默认 commissioning 仍为2 mm/s、1°/s、关节求解2°/s及4°/s²，原奇异区17/30不变。

intermediate 为10 mm/s、5°/s、求解关节15°/s及30°/s²；normal 为30 mm/s、10°/s、求解关节30°/s及60°/s²。两者是待实机验证的配置，不是已开放的操作员等级。夹爪独立保持0.025/s，本轮不改变夹爪力、行程、初始化或故障行为。

Jazzy官方Servo、KDL及数值平滑插件沿用v35/v34固定二进制。仅使用上游参数，不修改上游奇异处理算法。高档位拒绝旧2.5.10路径。每次虚拟运行保存独立源码副本和实际ROS参数；没有覆盖系统安装或原实验源。

## 边界处理修复

官方Servo在奇异停止时可以只发布状态、不再发布轨迹。此前网关会把这样的轨迹空缺当150ms断流并撤销准备，妨碍正常退回。现在根据上游明确的奇异/模型碰撞/关节边界状态丢弃残余轨迹、停止已运动设备，保留控制会话；静止时不反复重置桥接epoch，使切换关节模式或反向输入能实际到达Servo。未知轨迹断流、反馈失效、设备报警和模型子进程错误仍走异常停止。

专项验证覆盖残余候选拒绝、只Stop一次、准备状态保留、退回再次出目标，以及原始反馈丢失不能被边界提示遮蔽。35项通过。真实停止回包和位移尚待现场条件满足后验证。
