# E6 遥操作与示教采集：第一阶段模拟闭环验收

用户明确要求实施模拟闭环计划，取代此前暂停编码的讨论阶段。实现位于 `codex/e6-teleop` 分支的 `teleop/`，旧骨架删除但仍保存在 Git 历史（开发前基线 `e902dbe`）。本阶段没有连接 E6 或 X5，也没有发送机械臂、CAN、IO 或相机命令。

## 已交付

React 19 / TypeScript / Vite 本地工作台，MuJoCo 3.14.0 官方 E6 运动学模型，两进程仅监听 127.0.0.1 的 8765/8766。末端六自由度增量控制、DLS IK、四元数组合、基座/工具坐标、连续夹爪开度、手柄和键盘输入、单控制者租约、原始 episode、官方 LeRobot Dataset v3 导出、PyAV 读回以及浏览器数据浏览已接通。

安装和启动说明：[teleop/README.md](../teleop/README.md)，本机可双击 [teleop/launch.cmd](../teleop/launch.cmd)。数据默认在 `datasets/e6_teleop/`，不进 Git、不上传。原始记录、LeRobot 视频与各次初始测试均保留。

固定模型提交 `ec201c40d5db63185a3593ec9c39f80fe25aa527`，原始 URDF、七个网格和上游许可证带 SHA 校验；LeRobot 固定 `8c920c4270460851cedd2737657584586d3dc66f`（0.6.2）。运行时为 uv 管理 Python 3.12.13，torch 2.8.0+cpu，PyAV 15.1.0。Conda 3.12.2 环境曾发生 MuJoCo DLL 初始化失败，迁到独立运行时后恢复；未修改 Conda、驱动或系统安全设置。

## 测试结果

24 项 Python 测试、6 项前端测试通过，TypeScript/Vite 生产构建通过，完整 bootstrap 安装/构建流程通过。测试内容包括：独立 URDF FK 与 MuJoCo 的 12 组数值比较、六轴 FK/IK 闭环、关节限位、不可达目标、四元数跨 ±180°、基座/工具组合差异、精细速度、夹爪保持，以及重复/乱序/已消费/过期租约、失焦、设备丢失、第二控制者、断连与回中重新准备。

飞智存档 XInput 动态输入（20,244 次无错误读取）转换为 standard 浏览器布局后回归，覆盖三通道正负方向、14个标准按钮、LT/RT 全范围和肩键。该项是归档输入的映射测试，本轮浏览器未检测到实体手柄，不能称实体手柄在最终页面的逐键动态测试或蓝牙验收已完成。

实际浏览器界面验证了键盘正 X 平移、旋转模式、工具坐标、连续夹爪开度、释放保持、文本编辑保护、原始片段浏览、官方读取器数据浏览，以及索引 600 跨到第二个 episode 的首帧。浏览器初次键盘录制 925 帧，也已独立导出读回。

最终两进程 WebSocket 验收使用明确标记的软件合成输入，包含三段约 30 秒记录：

| 结果标签 | 时长 | 帧数 | 与当前观测不同的有效关节动作帧 |
|---|---:|---:|---:|
| success | 30.016 s | 600 | 555 |
| failure | 30.110 s | 600 | 579 |
| aborted | 30.005 s | 602 | 564 |

逐帧检查 `effective_action_t == observation_(t+1)`，同时确认大量 `action_t != observation_t`，说明标签来自动作而不是复制当前或下一帧状态。动作和图像在同一个原始样本内关联，图像先于该动作应用。中止记录保留，默认导出返回 HTTP 400。录制写盘故障注入另验证了停止、保存中止原因和拒绝不完整导出；进程异常退出的缺摘要/截断记录也可以查看，不标记为完整。

成功和失败两段通过固定官方 writer 的 `create/add_frame/save_episode/finalize` 合并为 `datasets/e6_teleop/lerobot/acceptance_final/`：

- 共 1,200 帧、两个 episode；每一行状态/动作标签和帧索引通过官方表读取验证。
- PyAV 解码实际 H.264 视频共 1,200 帧，PTS 递增，640×360。编码器日志确认 libx264 CPU，未使用硬件编码。
- 每段首/中/末图像与官方视频读回帧对比，最大像素平均绝对误差 0.714/255，属于有损编码差异。没有宣称逐像素无损。
- DataLoader 动作及状态 `[8,7]`，图像 `[8,3,360,640]`；前后 50 ms 时间窗在各段首尾，包括内部 episode 边界，正确填充而不跨段取样。
- 姿态保留在 raw；默认策略特征为六轴 rad＋归一化夹爪开度。LeRobot 时间轴为 `index/20`，原始高精度单调时间保留，未把各主机时钟直接相减。

## 证据与限制

证据目录 [docs/evidence/teleop_simulation_20261004](evidence/teleop_simulation_20261004/) 包含最终 `acceptance.json`、初始验收、录制故障、`lerobot_validation.json`、浏览器截图、测试摘要和源码/资产哈希。数据集与原始图像本地保留，目录受 `.gitignore` 保护。

本项目使用 Link6 原点作为默认模拟控制点，夹爪、相机和目标球仅供界面/数据链路演示。它没有接触动力学、抓放、真实附件避障、实机 TCP 标定、连续控制验收、训练或动作回放接口。success/failure 为操作者指定的模拟 episode 标签，不是物理任务结果。2.4G 手柄历史测试与蓝牙连接不可混称。

下一阶段可沿用协议增加 X5/E6 设备适配器；应先独立验收真实 TCP、附件几何、状态新鲜度、速度控制和网络停止，而不是把本次模拟目标直接下发给实机。
