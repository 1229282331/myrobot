# E6 手柄／键盘工作台使用说明

当前已交付 **v59 机械臂遥操作版本**：真实机械臂手柄／键盘控制、RGB／深度显示和原始示教录制均开放。夹爪连续闭合未到位，因此本版本禁用 CAN 配置、夹爪初始化与夹爪输入；页面明确显示“夹爪暂未开放”。这不是完整第三阶段验收通过。

机械臂限速为 2 mm/s、1°/s，精细模式为 25%；局部范围为新稳定基准周围 50 mm、10°，关节相对基准不超过 10°。首次上手先选键盘或手柄，回中并松开允许动作键，点“准备控制”，再小幅操作。当前人工实机手柄验收待用户完成；合成信号通过记录保留。

手柄接本 PC 的 2.4G 接收器；PC 经无线 SSH 连接 X5，E6 网线直连 X5。工作台地址为 <http://127.0.0.1:8765/>。操作员入口为 `teleop/launch-control-live.cmd`，启动前检查验收档案与源码 SHA；未完成验收的版本不会开放实机控制。

## 开始使用

1. 开启 E6、X5，确认人员离开运动区域、附件线缆留有余量、硬件急停可用。
2. 双击 `teleop/launch-control-live.cmd`。SSH 使用既有密钥或终端内输入的密码，密码不写入配置文件。
3. 查看新 RGB 画面、机械臂模式／使能／错误和数据新鲜度。启动不会自动使能或运动。
4. 若机械臂未使能，执行独立使能；等待至少 5 秒稳定观察。每次新会话以当前稳定姿态建立局部工作区，不能沿用上次未使能的起点。
5. 本版本夹爪禁用，无需初始化；LT／RT 和 F／R 不会发送夹爪动作，夹爪开度显示未知。
6. 选择键盘或手柄，松开允许动作键并回中，点“准备控制”。使用手柄时先按一下手柄，让浏览器识别，再保持网页焦点。

## 输入映射

| 功能 | 手柄 | 键盘 |
|---|---|---|
| 允许动作 | 按住 LB | 按住 Space |
| 三个轴 | 左摇杆左右／上下、右摇杆上下 | A/D、S/W、Q/E |
| 平移／旋转 | X | Tab |
| 基座／工具坐标 | Y | C |
| 25% 精细速度 | 按住 RB | 按住 Shift |
| 夹爪（当前禁用） | LT／RT 无动作 | F／R 无动作 |
| 软件停止 | Back | Esc |
| 开始录制 | Start | Enter |
| 结束并标记成功／失败 | A／B | 1／2 |

模式和坐标系切换须松开允许动作键并回中。松开 LB／Space 后停止机械臂积分并请求 Stop。文本编辑、失焦、输入断连时不发送运动输入。软件停止、控制器确认和实际静止在界面分别显示；软件停止不能替代硬件急停。

## 工作区与恢复

初版操作员范围以已验收档案为准：法兰原点 Tool0，基准周围 50 mm、姿态 10°、各关节相对基准 10°；可达性、跟随与模型检查可提前拒绝。模型夹爪与相机几何用于示意，不代表真实 TCP 或完整避障。

v58 控制周期仍为 50 ms，完整事务硬期限为 75 ms。已确认且在 50～75 ms 内完成的短时尖峰会记入“事务余量”计数并继续运行，过时周期直接跳过，不积压或追赶。本项目Stop等待确认时，若控制器制动目标与最后接受目标差≤0.1°且实际跟随制动目标差≤0.05°，容纳该有界过渡，期间不发送新动作；最终静止门槛仍为0.05°。反馈超过 100 ms、输入超过 250 ms、RGB 超过 500 ms，以及未确认动作或设备碰撞仍触发停止。该软件余量不是厂家实时保证，机械臂速度和工作区没有随之扩大。

有限恢复只适用于已分类的短时异常，包括输入在IK期间跨过250ms期限：Stop 确认并且实际静止，同源健康回中输入至少 5 秒后可重新准备，随后重新按允许动作键。每 60 秒最多 3 次。它不补发旧目标，不自动使能、清错、Continue 或初始化夹爪；碰撞、堵转、未确认命令等保留停止状态。手柄断连重连后须回中并显式准备。

## 示教与退出

实机示教保存到 `datasets/e6_teleop/hardware_demonstration/raw/`，包含输入、候选目标、控制器接受事件、动作前观测、原始反馈、RGB 与无损深度及关联。原媒体在 X5 暂存，片段结束后校验回传；回传期间暂停控制，完成后重新准备。中止和不完整记录保留供检查，真实数据暂不导出 LeRobot 动作数据。

关闭工作台终端时 Ctrl+C 先停止控制并释放本次资源，保持既有使能。准备下机时另行执行项目约定的收臂、下使能及 X5 关机流程。CAN 关闭通信不表示夹爪 24V 已断电。

最终实机实体手柄验收需要操作者完成；合成映射信号和模拟实体手柄验收不能替代它。受测档位及交付状态见同目录的生产集成验收报告。
