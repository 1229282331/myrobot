# DCW与OmniPicker共用转接盘的固定方案

2026-09-24。用户决定购买DCW，尚未确认已付款/到货；明确原E6→OmniPicker铝转接盘还没加工，可以一起改设计。以下为结构初设，未导出新生产CAD，原R2文件未改动，也不包含相机安装座。未操作机器人或相机。

## 推荐结构

**用户后续选择：优先改用DCW底部单孔固定，查找轻量通用支架；背面双孔方案保留为备选。** 用户指出底孔方向更合适。官方V2.5 §5.1底部/长侧单孔标M3，有效牙深5.5mm；不是摄影常见的1/4-20（公称直径6.35mm）。具体二手外壳仍以实物匹配为准。

E6 → 带外伸安装耳的铝转接盘 → OmniPicker原后盖/本体；同一转接盘外伸耳 → 可拆相机支架 → DCW。相机安装在夹爪根部上方，观察指尖和两指之间的工作区。这里的上方是随工具运动的相对方向。

- 底孔方案：转接盘安装耳接小型L形/可锁紧俯仰支架，M3螺钉从托板下方穿过光孔/槽孔拧入DCW底孔；托板加靠边或限位块防绕单孔转动，不能只靠线材限位。优先短支撑、轻量铝件，不默认增加摄影球头或魔术臂。
- 通用性分两层：支架若是光孔/槽孔且螺钉可更换，可适配M3（必要时匹配垫片/衬套）；自带不可更换1/4公螺杆的摄影支架不能直接拧入M3。支架到转接盘的孔位也须匹配。2mm夹持厚配平底头M3×6的名义旋入4mm，仍仅为候选。
- 现货检索：搜到标题为DaBai DCW2/D415/D435的可调支架索引，但淘宝goods详情被浏览器站点安全策略阻止，未核实材料、质量、螺钉和DCW兼容性；没有尝试绕过。独立闲鱼搜索“相机 M3 支架”“DCW 支架”未找到明确匹配条目。因此本轮没有确认可直接下单的SKU，不把DCW2标题当成DCW适配证据。
- 保留原R2的E6与夹爪安装孔、中央避让，以及用户要求的外圈8个备用孔。在圆盘外缘增加独立安装耳，设置两处M3紧固位置供相机支架使用。耳的具体尺寸/方向需结合插头和工具包络确定；不得在现有薄孔间材料处随意补孔。
- 原R2外圈8孔是对E6的通孔/沉头孔，不是转接盘上的M3螺纹，不能直接把它们当作现成相机螺纹座。后盖也可能遮挡相应位置。
- 相机支架优先采用局部折弯加筋的2mm铝板；可用打印样件先验证视角。旧方案采用官方背面双M3安装位，现降为备选，主选改为上述底孔方案。不会利用活动夹指或拆换夹爪壳体结构螺钉承载相机。
- 调试时可以通过支架槽孔/可换角度件调整俯仰和前后位置，使用时锁紧；保持相机到工具的刚性关系。调整后重新检查/标定外参。
- 相机横向布置，镜头朝向指尖工作区；优先根部位置，必要时朝腕部方向后移。具体俯仰角由实际画面确定，不把任意固定角度当成最优视角。
- 避开DCW两侧散热孔、Type-C插头，以及OmniPicker的USB/六芯线；相机线在支架处做应力释放。检查夹指完全开闭时的扫掠体积，不只检查闭合状态。
- 相机支架、增耳和新增紧固件争取控制在约20–30g，是设计目标而非已建模质量/刚度结论。当前不含这些新增件的基线约572.7g，后续需重新计算整套质量和质心。

## 官方安装证据及纠正

本轮通过飞书预览直接查看《对外版DaBai DCW-DW Datasheet V2.5》：

- §3.4.1，印刷第14–15页 / PDF第18–19页：固定支架安装示意；正文明确M3.0螺钉2颗；相机固定螺孔有效牙长4.5mm；建议支架厚2mm；螺钉长6.0–6.5mm。
- §5.1，印刷第18页 / PDF第22页：结构图中USB接口附近的2×M2标注为数据线锁固螺丝；另标有M3及有效牙深5.5mm，与安装正文4.5mm存在差异。
- 前一轮参数表的2×M2不能直接用于支架设计。按明确的支架安装章节先选M3，先采用4.5mm较保守边界；最终仍需核对所购二手实物，不能强行拧入不匹配螺纹。
- 采用实际2mm夹持厚度、无额外垫片的平底头M3×6，名义旋入4mm，作为候选；若改成打印厚支架、加垫片或沉头，必须重新核算长度，不沿用该算式。
- 本轮公开图未读到背面两孔可靠的中心距标注，不按图片比例估计后投产。出最终相机托架CAD前，需要匹配实物的机械图或背面孔距、孔到外壳边缘位置与允许旋入深度。

## 视角与深度边界

DCW深度近端为20cm，需从镜头到物体计算。优先将相机放在根部并避免不必要的前伸，但不能保证这样就能获得接触阶段深度；若不足20cm，接触阶段按RGB设计。没有必要为了凑20cm而增加长悬臂，导致碰撞包络与挠度增加。

安装验收要确认：两指接触区同时可见、夹爪不过度挡住桌面、开放和闭合状态不干涉、插头可以正常插拔、线材不拉扯相机。最终加工前补齐相机孔位，并结合夹爪和接头实物确定安装耳朝向。当前是确定结构路线，不是完成机械装配/强度/疲劳验证。
