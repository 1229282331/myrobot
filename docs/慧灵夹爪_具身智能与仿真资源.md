# 慧灵 HITBOT 夹爪用于 E6：型号、PNP、开发与仿真资源

核查日期：2026-09-17。目标：本体不超过 1500 元、配件另算；先桌面抓取和模仿学习，后续适配 ACT、π0.5。此次只查公开网页、下载文档/CAD、静态阅读资料，没有连接硬件、安装上位机、执行控制命令或联系卖家。

## 结论与型号排序

慧灵可以用于具身智能，但要按具体型号和接口版本选择。当前最值得考虑的是 **Z-EFG-26 的 Modbus RTU 版本**；需要稍大行程可比较 **Z-EFG-C35**；只需 PNP 开合且重视重量时，比较 **Z-EFG-20S 的 PNP 版本**。这些型号仍属于工业平行爪，不具备 OmniPicker 的长指自适应包络机构。

| 型号 | 本体重 | 总行程 | 夹持力（厂家定义） | 开发特点 | 对 E6 的判断 |
|---|---:|---:|---:|---|---|
| **Z-EFG-26** | **450g** | **26mm，可调** | 6–15N | Modbus RTU、IO；位置/电流/夹持状态反馈；有 PNP 型资料 | 优先考察，有 400 元二手线索；只剩 300g 名义负载余量 |
| **Z-EFG-C35** | **500g** | **35mm，可调** | 15–50N | Modbus RTU、IO；位置/速度/电流/状态反馈；有 PNP 型资料；IP54 | 本轮新增候选；比26多9mm行程，余量250g，未核实≤1500元货源 |
| **Z-EFG-20S** | **350g** | **20mm，固定行程** | 8–20N，旋钮调节 | NPN/PNP 版本；IO开合与运动状态输出，未见连续位置查询接口 | 简单开合学习可用；不适合期待策略任意设定开度的路线 |
| Z-EFG-20F | 500g | 20mm，可调 | 1–8N | Modbus/IO与反馈；厂家推荐夹持物≤100g | 适合轻柔小物体，重量和行程对E6不占优势 |
| Z-EFG-26P | 500g | 26mm，可调 | 15–50N | Modbus/IO与反馈 | 主要增加夹力，不增加行程；型号P不能单独证明是PNP版本 |
| Z-EFG-30 | 550g | 30mm，可调 | 10–40N | 手册分别提供Modbus及脉冲/IO版本 | 只剩200g名义余量；不能把所有二手后缀都当485型号 |
| Z-EFG-50 | 700g | 50mm | 15–50N | 系列官网规格 | 只剩50g，加入配件后不适合作E6常规抓取方案 |
| Z-EFG-100 | 925g | 90mm（官网表） | 35–60N | Y型电爪 | 本体超出E6额定负载；形态不能抵消超重 |
| Z-EFG-40-100 | 1000g | 40mm | 手册写30–200N | Modbus/IO | 超重，排除；不可将型号100直接当最大力规格 |

重量来源为厂家[系列参数表](https://www.hitbot.cc/z-efg/)和对应型号手册。C35、40-100另从官方下载目录取得手册核查。表中余量只做750g减本体的算术，还要扣除手指、转接板、螺丝、随动线缆、相机及物体，并核对重心限制。改长指会增加重量和力矩，不增加本体行程，也不会自动变成自适应爪。

网页与手册有个别不一致：26P尺寸高度官网写108mm、下载手册写103mm；30峰值电流官网表写2A、手册写1A；20F行程时间网页与手册也不同。加工、供电应以实物匹配版本为准，不混抄参数。

## Z-EFG-26 的开发证据

[官方手册本地副本](../research/grippers/HITBOT_EFG26_manual.pdf)版本V_2023.05.25：PDF第5页线序和RS485参数；第6页协议；第7页工作流程和IO。

| 项目 | 手册定义 | 对算法的意义 |
|---|---|---|
| 目标位置 | 0x0002，float，mm | 可以输出中间目标位置，不限于开合 |
| 目标速度 | 0x0004，float，mm/s | 可配置运动速度 |
| 夹持电流 | 0x0006，float，A | 电流控制参数，不等于指尖测力值 |
| 夹持状态反馈 | 0x0041；到位/运动中/夹持/掉落 | 可记录与检查动作结果 |
| 夹持位置反馈 | 0x0042，float，mm，独立只读寄存器 | 可作为开度观测的开发依据；需实测标定与更新频率 |
| 夹持电流反馈 | 0x0046，float，A | 可辅助分析负载和接触，不能当作牛顿值 |
| 速度反馈 | 0x0044，标记“保留” | 不把该版本的速度反馈保证为可用 |

相比钧舵EPG手册中的“当前位置/设定位置”矛盾，慧灵此处分别列出目标位置和独立位置反馈，定义更清楚。但没有实测过所售ALL-LMC版本，不能保证它与当前手册、字节序、反馈更新行为完全一致；浮点单位也不等于任意高的真实分辨率。

手册0x0006给的默认4A与本体峰值1A存在口径疑问，不能照抄该默认值作为调试建议。当前仅保存资料，不执行其中任何示例。后续以对应固件、电机电流定义及制造商限值为准。

Python开发可以使用pyserial配合Modbus库封装设备，不要求厂家必须提供专用Python包。需要完成连接、字节序、读写封装、超时处理、状态标定和时间戳同步，之后才能接入LeRobot等框架。

## PNP与E6：有明确可选路径

Z-EFG-26手册的IO说明明确写：NPN型有效为0V，PNP型有效为24V。两路输入组合选择4个预设夹持点位；两路输出组合表示到位、运动中、夹持或掉落。C35手册也列出了相同四种IO组合。**这是对应PNP版本的功能证据，不代表每台同名夹爪的IO电气类型都相同。**

Z-EFG-20S手册PDF第5页分别给出NPN/PNP线序，PNP控制输入明确支持24V PNP控制器；输出只表示运动状态。第3页明确20mm行程不可调。不要把20S、20F、20、26、26P的能力混用。

两条开发路线：

1. E6 DO → 匹配的PNP型夹爪输入：先做开合/预设动作，必要时用E6 DI接匹配状态输出。
2. PC USB-RS485 → Modbus型夹爪，同时PC网络连接E6：方便策略设定不同位置并记录反馈。采用一个运动命令来源；没有验证IO与总线混用时的仲裁，不承诺两者可同时控制。

E6六针末端口没有已确认的RS485针脚。26峰值1A、C35峰值1A、20S峰值0.6A；E6末端24V独立供电上限仍未核实，不能承诺用末端口给夹爪电机供电。26手册说明485与电源内部未隔离，工程集成时可优先考虑隔离USB-RS485并按手册处理接地。

**26手册明确上电会自动初始化并张开。** 这对用户当前未固定的机械臂特别相关：后续通电验收也须在完成固定后的合适台架进行，本轮没有通电或控制。

[官方下载中心](https://www.hitbot.cc/download/)按型号提供手册、3D图和安装尺寸图；“夹爪电缸上位机”栏目有HitBotDrive及说明书。

|---|---|
| Z-EFG-26 STEP | [已下载并解压](../research/grippers/ecosystem/Z-EFG-26.STEP)，真实STEP AP203，内部文件名匹配Z-EFG-26.STEP；未核对几何/装配版本 |
| Z-EFG-C35 STEP | [官方CAD压缩包](../research/grippers/ecosystem/HITBOT_EFGC35_CAD.zip)，内含EFG-C35（外发）.STEP；未建立关节或验证几何 |
| 20S/20F/26P/30等CAD | 官方目录有对应下载入口，未将所有型号模型都下载 |
| 上位机 | 官方提供HitBotDrive-1.0.12.20235-x86-Setup.exe；本轮没有下载或运行安装程序 |
| 独立夹爪Python SDK | 本轮未核实到像钧舵那样独立发布的专用SDK包；已有公开Modbus协议，可自行封装 |
| URDF / MuJoCo MJCF / Isaac USD | 本轮未取得可直接运行的26/C35专用仿真包；不宣称绝对不存在 |
| LeRobot适配器 | 未核实到现成26/C35驱动，需自行适配 |

公开搜索中的[kelo_hitbot_driver](https://github.com/kelo-robotics/kelo_hitbot_driver)已打开核查：它面向慧灵Z-Arm S922，通过机械臂控制器TCP接口提供ROS/C++运动命令。即便README有moveGripper，也不能当成E6上独立RS485夹爪驱动或夹爪仿真模型。搜索另有Z-Arm Python API，名称相似同样不能当作Z-EFG专用SDK。

CAD到仿真仍需：核对型号及法兰、加入实际夹指，拆分本体和移动件，建立两侧平移关节/耦合与限位，简化碰撞网格；动态抓取再加入质量惯性、驱动、接触摩擦和延迟标定。对实机示教及模仿学习，这不是必须先完成的门槛。

## 与EPG40-050如何取舍

| 比较项 | 慧灵Z-EFG-26 | 慧灵Z-EFG-C35 | 钧舵EPG40-050 |
|---|---|---|---|
| 本体重 | 450g | 500g | 厂家现行360g，旧资料400g |
| 总行程 | 26mm | 35mm | 40mm |
| 位置反馈资料 | 独立位置反馈寄存器，mm | 独立位置反馈寄存器，mm | 查询API有，手册语义有歧义 |
| Python开发 | 按公开Modbus协议封装 | 按公开Modbus协议封装 | 有官方系列SDK |
| PNP路径 | 指定PNP版本 | 指定PNP版本 | 指定带IO及电气匹配版本 |
| 已有几何资源 | 官方STEP | 官方STEP | 官方STEP条目，文件内部命名待核对 |
| 完整仿真包 | 未核实 | 未核实 | 未核实 |

如果你主要抓小物体、希望低成本做数据采集，400元26是值得验货的候选。若最终两家的完整可用报价接近，E6上优先保留重量更轻、行程更大的EPG40-050，再解决其反馈确认。若坚持PNP简单开合，20S有明确版本依据；若坚持现成仿真，当前两家都尚未满足。
