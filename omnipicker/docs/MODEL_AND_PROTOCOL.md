来源页面：https://www.agibot.com.cn/DOCS/PM/X1

下载：https://www.agibot.com.cn/file/ueditor/php/upload/file/20250114/robot_description.zip

下载于 2026-09-26，6,263,175 bytes，SHA-256：
`ab379eac6f8997fceca5dbc139cb6ccf8ae26e52f7791795f67ac3b2849132f5`。

官方目录完整保留。程序直接解析 `urdf/robot_urdf.xacro` 中静态 link/joint 元素，不运行 ROS / xacro；11 个 link、10 个 joint（8 转动、2 固定），9 个分件 STL。STL 按米解释后仅在渲染层转为毫米尺度，变换使用官方 origin、RPY、轴向与 visual origin，未调整单件装配坐标。`files.sha256.json` 提供解压文件哈希。官方资源版权属于原作者，原包未提供独立授权文件；本项目将其作为本地设备可视化资料保留。

## 空载名义联动

官方模型没有 mimic、开度到关节角标定或闭环动力学。本程序采用一个明确的显示假设：第三被动关节保持 URDF 零角，将第二连杆与指端固定点视作刚性组合，用圆交点闭合基座回连杆。

对于每一侧，在第一关节局部平面取基座 A、第二关节 B、第四关节参考点 E、回连杆轴 D。`|BE|` 和 `|DE|` 来自官方零位几何；给定第一关节角后，求满足两条长度约束的 E，取零位相连的连续分支，然后反解第二关节及回连杆角度。两侧符号相反。

输入 0–100% 在线性显示范围内对应第一关节 0 至 ±45°。这是**未经实物标定的显示映射**；闭合 E 是官方 joint4 参考点，不是测得的实际指尖。不能用于标定、碰撞规避、接触判断或训练位置标签。1001 个输入采样验证分支连续，闭合残差小于 1 µm（数值装配检查，不是实机精度）。URDF 四舍五入的 RPY 导致极小非平面误差。

## 原生 USB/Fibre

实现依据为本项目已静态核查的 REF-CLI v1.0.3 以及 2026-09-26 本机只读对照；运行时不调用 REF-CLI。

端点请求是 little-endian `seq:uint16, endpoint|0x8000:uint16, response_size:uint16, payload, interface_crc:uint16`。响应首两字节必须为本次 `seq|0x8000`，不匹配的 ACK 不会作为成功；剩余长度须符合属性类型。事务超时 0.5 秒，无写重试。

JSON 下载使用 endpoint 0、uint32 offset、每块最多 512 bytes，直到空块，协议版本尾字为 1。其他端点的 CRC 使用原始设备 JSON bytes，非反射多项式 0x3D65、初值 1、无最终异或。

函数参数、触发和返回值是不同端点。编号必须按设备定义动态解析：

| 函数 | 固件 330 | 固件 335 |
|---|---|---|
| `motor.ctrl.set_pos` | 写 65 float → 触发 64 | 写 70 float → 触发 69 |
| `motor.request_state` | 写 9 uint8 → 触发 8 → 读 10 bool | 写 14 uint8 → 触发 13 → 读 15 bool |

停止标志在运动参数写入与触发之间再次检查。USB 事务由唯一 QThread 顺序拥有，UI 只投递意图。

接口基线 `schema-fw330.json` 来自设备原始 JSON，SHA-256：
`3f3f05031d8b24d6e7e280da42fd48b264711be462f14116065bcf69985e6db1`，CRC16 十进制 9774。

升级后实物基线 `schema-fw335.json` SHA-256：
`02b7437d3e3adde61eb5b94da99a35965a9850e091eda85ee819c1c80777096b`，CRC16 十进制 41051。仅新增 `fw_hash`、`rs485_mode`、`modbus_mode`、`uart_baudrate`、`uart_stopbits`；既有函数参数、返回类型及属性访问权限不变，多个端点编号后移。原生驱动已实测读取全部62项标量属性及一次下使能请求返回 True；升级后未重做开合动作测试。详见 [升级记录](FIRMWARE_335_2026-09-26.md)。

旧 `local-network/omnipicker-usb-schema-2026-09-26.json` 被 REF-CLI 加入函数参数 `mode: r` 元数据。新原始定义与其逐项对照，仅缺少这些 CLI 辅助字段，端点、类型和访问属性一致；没有放宽未知设备的写校验。

## 调度与停止

普通控制意图队列有上限；手动目标只有一个最新值槽，最小下发间隔 50 ms，鼠标释放再次提交最后值。自动测试占有目标通道，人工目标被丢弃，不在结束后补发。停止位清空普通命令和最新目标，并在退出意图前执行；取消剩余测试并请求下使能。正在等待的单笔 USB 事务不能被强行撤销，停止最迟须等待这笔事务结束或超时；不把软件停止称为硬件急停。

临时参数逐项写入并读回，部分失败也保留原基准供恢复。未知接口禁止所有写操作，包含清错与下使能。模拟测试覆盖断连、停止失败、恢复及退出决策。
